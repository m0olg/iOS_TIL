### I. JSON 구조 읽기

<br>

# 1-1 JSON이란?

→ 서버와 앱이 데이터를 주고받을 때 자주 사용하는 데이터 형식

JSON은 데이터를 **키와 값**의 형태로 표현함

```json
{
  "name": "치이카와",
  "age": 3
}
```

- `"name"`: 키
- `"치이카와"`: 값
- `"age"`: 키
- `3`: 값

키는 큰따옴표로 감싸고 값에는 문자열·숫자·불리언·배열·객체 등이 올 수 있음


<br>
<br>


# 1-2 JSON의 기본 자료형

### 1) 문자열

문자나 글자를 표현하고 큰따옴표로 감쌈

```json
"name": "하치와레"
```

### 2) 숫자

정수나 소수를 표현함

```json
"age": 3
"height": 20.5
```

숫자는 큰따옴표 없이 작성함

### 3) 불리언

참 또는 거짓을 표현함

```json
"isFriend": true
```

`true`, `false`는 소문자로 작성하고 큰따옴표로 감싸지 않음

### 4) null

값이 없거나 비어 있음을 나타냄

```json
"nickname": null
```

`null`도 큰따옴표로 감싸지 않음

### 5) 배열

여러 값을 순서대로 담음

```json
"friends": ["치이카와", "하치와레", "우사기"]
```

배열은 대괄호 `[]`로 감쌈

### 6) 객체

여러 키와 값을 하나로 묶음

```json
"friend": {
  "name": "하치와레",
  "age": 3
}
```

객체는 중괄호 `{}`로 감쌈


<br>
<br>


# 1-3 JSON에서 주의할 점

### 1) 문자열과 키에는 큰따옴표 사용

JSON에서는 키와 문자열 값을 큰따옴표로 감싸야 함

```json
{
  "name": "치이카와"
}
```

작은따옴표를 쓰거나 키에 따옴표를 생략하면 올바른 JSON이 아님

### 2) 각 항목은 쉼표로 구분

키와 값으로 이루어진 항목이 여러 개면 쉼표로 구분함

```json
{
  "name": "치이카와",
  "age": 3
}
```

마지막 항목 뒤에는 쉼표를 붙이지 않음

### 3) 키와 값 사이에는 콜론 사용

`키: 값` 형태로 작성함

```json
"favoriteFood": "푸딩"
```

### 4) 자료형 구분하기

`"3"`은 문자열이고 `3`은 숫자임

```json
{
  "age": 3,
  "characterId": "chiikawa01"
}
```

숫자처럼 보여도 *계산할 필요가 없는 식별자* 는 **문자열로 표현**할 수 있음

<br>
<br>



# 1-4 중첩된 JSON 읽기

객체 안에 다른 객체나 배열이 들어갈 수 있음

```json
{
  "name": "치이카와",
  "profile": {
    "favoriteFood": "푸딩",
    "friend": "하치와레"
  },
  "friends": ["하치와레", "우사기"]
}
```

읽을 때는 바깥 객체부터 안쪽으로 따라가면 됨

- `"name"`의 값: `"치이카와"`
- `"profile"`의 값: 객체
    - `"favoriteFood"`의 값: `"푸딩"`
    - `"friend"`의 값: `"하치와레"`
- `"friends"`의 값: 배열
    - 첫 번째 값: `"하치와레"`
    - 두 번째 값: `"우사기"`


<br>
<br>


# 1-5 서버 응답 JSON 읽기

예를 들어 서버가 다음 데이터를 응답했다고 하자

```json
{
  "success": true,
  "data": {
    "id": 1,
    "name": "치이카와"
  },
  "message": "캐릭터 조회 완료 !!!!!"
}
```

이 JSON은 다음처럼 읽을 수 있음

- `"success"`: 요청 처리 성공 여부
- `"data"`: 실제 캐릭터 데이터
    - `"id"`: 캐릭터 식별자
    - `"name"`: 캐릭터 이름
- `"message"`: 처리 결과를 설명하는 메시지

> 다만 JSON의 키 이름이나 구조는 API마다 다르므로 실제 응답 형식은 API 문서를 확인해야 함


<br>
<br>


# 1-6 정리

* JSON은 키와 값으로 데이터를 표현하는 형식
* 키와 문자열은 큰따옴표로 감쌈
* 값에는 문자열, 숫자, 불리언, `null`, 배열, 객체 등이 올 수 있음
* 배열은 `[]`, 객체는 `{}`로 표현
* 중첩된 JSON은 바깥 구조부터 안쪽으로 따라가며 읽으면 됨
* 실제 서버 응답의 구조와 키 이름은 API 문서를 기준으로 확인해야 함
