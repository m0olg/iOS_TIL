## 카카오 로그인
# 01 카카오 로그인 개념 및 흐름
→ 카카오 로그인은 **사용자가 카카오 계정으로 내 앱에 로그인할 수 있게 해주는 기능**, 카카오가 로그인 과정을 처리하고 내 앱에는 로그인 결과만 전달

> 카카오 OAuth 로그인 = 카카오에게 로그인을 맡기고 내 앱은 로그인 결과를 받는 방식 !!

### ① 일반 로그인과 카카오 로그인 비교
#### 1) 일반 로그인
1. 사용자가 내 앱에 아이디와 비밀번호를 입력
2. 내 앱이 입력받은 로그인 정보를 내 서버로 전송
3. 내 서버가 로그인 정보를 확인
4. 내 서버가 로그인 결과를 내 앱에 전달
> 일반 로그인에서는 내 앱이 사용자의 아이디와 비밀번호를 직접 받음

#### 2) 카카오 OAuth 로그인
1. 사용자가 내 앱에서 카카오 로그인 버튼을 누름
2. 카카오 로그인 화면이 열림
3.  사용자가 카카오 화면에서 카카오 계정으로 로그인
4. 카카오가 로그인 성공 결과를 내 앱에 전달
> 카카오 OAuth에서는 내 앱이 사용자의 카카오 비밀번호를 알 수 없음

### ② 흐름
```
카카오 로그인 성공
        ↓
Access Token 받기
        ↓
사용자 정보 요청
        ↓
내 서비스에 회원 정보가 있는지 확인
        ↓
회원이면 로그인
(신규 사용자면 회원가입 후 로그인)
```
카톡 로그인이 성공하면 보통 요런 순서로 진행됨

## 02 카카오 OAuth에서 나오는 용어
| 용어 | 쉬운 뜻 |
| --- | --- |
| **Client** | 카카오 로그인을 사용하는 내 앱 |
| **Provider** | 로그인을 제공하는 카카오 |
| **SDK** | 카카오 로그인을 쉽게 사용할 수 있게 만든 도구 |
| **Access Token** | 로그인 성공을 증명하는 출입증 |
| **Scope** | 앱이 사용할 수 있는 사용자 정보의 범위 |
| **Bundle ID** | iOS 앱을 구분하는 고유 이름 |
| **URL Scheme** | 로그인 후 카카오에서 내 앱으로 돌아오기 위한 주소 |

## 03 Client와 Provider
#### ✨ 카카오 오어스에선 두 주체가 중요함
* <mark>**Client**</mark> : 카카오 로그인을 이용하는 앱
* <mark>**Provider**</mark> : 로그인 기능을 제공하는 카카오

<u>내 앱</u>은 카카오에 **사용자 로그인을 요청** \
<u>카카오</u>는 로그인 **성공 여부를 확인**한 뒤 그 *결과를 내 앱에 전달*

# 04 Access Token & Scope
### [!! 자세한 건 OAuth개념에서 6번, 7번 참고 !!](https://github.com/m0olg/iOS_TIL/blob/main/OAuth/01.%20OAuth_%EA%B0%9C%EB%85%90.md)

→ `Access Token`은 로그인한 사용자를 확인하기 위한 인증 정보 (쉽게 말하면 앱이 카카오에 보여주는 출입증..?)

`Access Token`을 사용하면 앱이 카카오에 "**이 `엑세스 토큰`을 가지고 있는 사용자의 정보를 알려줘**"라고 <u>요청</u>할 수 있음 

> Access Token은 비번은 아니지만 다른 사람에게 노출 되면 안 됨

---

→ `Scope`는 앱이 카카오에서 사용할 수 있는 정보의 범위

앱은 필요한 정보한 요청하고 사용자는 해당 정보 제공에 동의 해야함 !!

# 05 SDK란?
카카오 로그인을 구현하려면 다음 기능을 만들어야함
1. 카카오 로그인 화면 열기
2. 로그인 결과 받기
3. 엑세스 토큰 처리
4. 로그인 후 앱으로 돌아오기
5. 사용자 정보 요청

카카오 SDK를 사용하면 이런 기능들을 쉽게 이용 가능함

```
내 앱
  ↓
카카오 SDK
  ↓
카카오 로그인
```

#### Swift에선 로그인 기능을 [서비스](https://github.com/m0olg/iOS_TIL/blob/main/%F0%9D%9F%AC%F0%9D%9F%B1_%F0%9D%90%8D%F0%9D%90%9E%F0%9D%90%AD%F0%9D%90%B0%F0%9D%90%A8%F0%9D%90%AB%F0%9D%90%A4_%F0%9D%90%9A%F0%9D%90%A7%F0%9D%90%9D_%F0%9D%90%80%F0%9D%90%AB%F0%9D%90%9C%F0%9D%90%A1%F0%9D%90%A2%F0%9D%90%AD%F0%9D%90%9E%F0%9D%90%9C%F0%9D%90%AD%F0%9D%90%AE%F0%9D%90%AB%F0%9D%90%9E/00\)%20SwiftService_%EB%B3%B5%EC%8A%B5/Service.md)로 분리 가능
```swift
final class KakaoLoginService {

    func login() {

    }
```

# 06 Bundle ID란?
→ iOS 앱의 고유한 이름으로 Xcode의 Bundle ID와 카카오 개발자 사이트에 등록한 Bundle ID가 같아야함

서로 다르면 카카오가 앱을 제대로 확인하지 못해 로그인 실패 가능성 ⬆️

# 07 URL Scheme이란?
카카오 로그인은 앱 밖의 카카오 로그인 화면을 열었다가 다시 앱으로 돌아오는 방식

### 이때‼️<sub>카카오가 어느 앱으로 돌아가야 하는지 알려주는 것이</sub>URL Scheme임

```
내 앱 → 카카오 로그인 화면 → 로그인 성공 → URL Scheme을 통해 내 앱으로 돌아옴
```
URL Scheme은 앱의 전용 주소라고 생각하면 쉬움

# 08 로그인 후 사용자 정보 받기
로그인에 성공하면 Access Token을 이용해서 사용자 정보를 요청 가능 !! (사용자 동의가 있어야 받을 수 있따)

    1. 카카오 로그인 성공
    2. Access Token 받기
    3. Access Token으로 사용자 정보 요청
    4. 닉네임, 이메일 등 받기

```swift
final class KakaoUserService {

    func fetchUserInfo() {
        // 카카오 SDK로 사용자 정보 요청
    }
}
```

# 09 정리
* 카카오 OAuth는 카카오 계정으로 내 앱에 로그인하는 기능
* 내 앱은 사용자의 카카오 비밀번호를 직접 받지 ❌
* 카카오가 로그인과 인증을 처리
* 로그인 성공 후 `Access Token`을 받을 수 있음
* `Access Token`으로 허용된 사용자 정보를 요청할 수 있음
* 카카오 SDK가 로그인 과정을 쉽게 처리해줌
* iOS에서는 `Bundle ID`와 `URL Scheme` 설정이 중요함

> ### ✨ 카카오 OAuth는 카카오에게 로그인을 맡기고 내 앱은 로그인 결과와 Access Token을 받아 사용자를 로그인시키는 방식 !!!!!!!!!!
