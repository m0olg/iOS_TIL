# 01 로그인 개념 및 흐름
→ 구글 로그인은 **사용자가 구글 계정으로 내 앱에 로그인할 수 있게 해주는 기능**, 구글이 로그인 과정을 처리하고 내 앱에는 로그인 결과만 전달

> 구글 OAuth 로그인 = 구글에게 로그인을 맡기고 내 앱은 로그인 결과를 받는 방식 !!

### ① 일반 로그인과 구글 로그인 비교

#### 1) 일반 로그인

1. 사용자가 내 앱에 아이디와 비밀번호를 입력
2. 내 앱이 입력받은 로그인 정보를 내 서버로 전송
3. 내 서버가 로그인 정보를 확인
4. 내 서버가 로그인 결과를 내 앱에 전달

> 일반 로그인에서는 내 앱이 사용자의 아이디와 비밀번호를 직접 받음

#### 2) 구글 OAuth 로그인

1. 사용자가 내 앱에서 구글 로그인 버튼을 누름
2. 구글 로그인 화면이 열림
3. 사용자가 구글 화면에서 구글 계정으로 로그인
4. 구글이 로그인 성공 결과를 내 앱에 전달

> 구글 OAuth에서는 내 앱이 사용자의 구글 비밀번호를 알 수 없음

### ② 흐름

```
구글 로그인 성공
        ↓
Access Token 받기
        ↓
사용자 정보 요청
        ↓
내 서비스에 회원 정보가 있는지 확인
        ↓
회원이면 로그인하고 신규면 회원가입 후 로그인
```

# 02 구글 로그인에서 나오는 용어
| 용어 | 쉬운 뜻 |
| :--- | :---: |
| **Client** | 구글 로그인을 사용하는 내 앱 |
| **Provider** | 로그인 기능을 제공하는 구글 |
| **SDK** | 구글 로그인을 쉽게 사용할 수 있게 만든 도구 |
| **Access Token** | 구글의 사용자 정보에 접근할 수 있는 인증 정보 |
| **ID Token** | 어떤 구글 계정으로 로그인했는지 확인하는 정보 |
| **Scope** | 앱이 사용할 수 있는 사용자 정보의 범위 |
| **Client ID** | 구글이 내 앱을 식별하기 위한 값 |
| **URL Scheme** | 로그인 후 구글에서 내 앱으로 돌아오기 위한 주소 |

# 03 `Access Token`과 `ID Token`
구글 로그인에선 액세스 토근과 아이디 토근을 구분해야함


### `Access Token`
`Access Token`은 <mark>구글 API에 접근할 수 있는 인증 정보</mark>
예를 들어 허용된 범위 안에서 구글 사용자 정보를 요청할 때 사용됨

### `ID Token`
`ID Token`은 사용자가 <mark>어떤 구글 계정으로 로그인 했는지</mark> 확인하기 위한 정보

```
Access Token → 구글 API 사용
ID Token → 로그인한 사용자 확인
```
둘 다 인증과 관련 있지만 역할이 다름

<br>
<br>

# 04 구글 로그인 실패 원인
* `Client ID`가 잘못 설정
* `URL Scheme` 설정이 빠짐
* 앱의 `Bundle ID`가 등록 정보와 다름
* 구글 로그인 SDK 설치가 잘못됨
* 사용할 API나 동의 항목 설정이 부족함
* 로그인 결과를 앱에서 처리하지 않음
* 구글 개발자 콘솔 설정이 완료되지 않음

> #### 특히 처음엔 Client ID, Bundle ID, URL Scheme을 먼저 확인하는 게 좋음 !!!!!!

# 05 카카오 로그인과 구글 로그인 비교
| 구분 | 카카오 로그인 | 구글 로그인 |
| :--- | :--- | :--- |
| **로그인 제공자** | 카카오 | 구글 |
| **앱 식별 설정** | 카카오 앱 키 | Client ID |
| **로그인 SDK** | 카카오 SDK | 구글 로그인 SDK |
| **로그인 결과** | Access Token 등 | Access Token, ID Token |
| **주요 사용자 정보** | 닉네임, 이메일 등 | 이메일, 이름, 프로필 사진 등 |
| **앱으로 돌아오기** | URL Scheme | URL Scheme |

둘다 기본 원리는 비슷비슷

# 06 정리
* 구글 OAuth는 구글 계정으로 내 앱에 로그인하는 기능
* 내 앱은 사용자의 구글 비밀번호를 직접 받지 않음
* 구글이 로그인과 인증을 처리
* `Access Token`은 구글 API 사용에 활용
* `ID Token`은 어떤 사용자가 로그인했는지 확인하는 데 사용됨
* `Client ID`는 구글에서 내 앱을 식별하는 값임
* iOS에서는 `Bundle ID`와 `URL Scheme` 설정이 중요 !!!!!

> ### ✨ 구글 OAuth는 구글에게 사용자 인증을 맡기고 내 앱은 Access Token이나 ID Token을 받아 로그인을 처리하는 방식
