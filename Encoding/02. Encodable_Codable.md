## `Encodable`

<br>

# 01 `Encodable`이란?

→ `Encodable`은 Swift 타입의 데이터를 외부 데이터 형식으로 변환할 수 있도록 해주는 프로토콜

예를 들어 시사의 정보를 서버에 보내려면 `Character` 타입이 `Encodable`을 채택해야 함

```swift
struct Character: Encodable {
    let name: String
    let favoriteFood: String
}
```

`Character`가 `Encodable`을 채택하면 `JSONEncoder`로 객체를 JSON `Data`로 변환할 수 있음

```swift
let sisa = Character(
    name: "시사",
    favoriteFood: "라멘"
)

let data = try JSONEncoder().encode(sisa)
```

<br>
<br>



# 02 `Encodable`과 `JSONEncoder`의 관계

`Encodable`은 **해당 타입을 인코딩할 수 있다는 것을 나타내고**, `JSONEncoder`는 실제로 인코딩을 수행함

| 요소 | 역할 |
| :--- | :--- |
| `Encodable` | 타입이 인코딩될 수 있도록 함 |
| `JSONEncoder` | 객체를 JSON `Data`로 변환 |

<br>

```
Encodable을 채택한 타입
    ↓
JSONEncoder로 인코딩
    ↓
JSON Data
```


<br>
<br>


# 03 `Encodable`을 채택하지 않은 경우

아래처럼 <mark>`Character`가 `Encodable`을 채택하지 않으면 `JSONEncoder`로 변환할 수 없음

```swift
struct Character {
    let name: String
    let favoriteFood: String
}
```

인코딩하려면 다음처럼 `Encodable`을 채택해야 함

```swift
struct Character: Encodable {
    let name: String
    let favoriteFood: String
}
```

<br>
<br>



# 04 `Encodable` 정리

* `Encodable`은 Swift 타입을 외부 데이터 형식으로 변환할 수 있도록 해주는 프로토콜임
* JSON으로 인코딩할 타입은 `Encodable`을 채택해야 함
* 실제 JSON 변환은 `JSONEncoder`가 수행함

<br>

> ### ⇒ `Encodable`은 시사의 정보를 담은 `Character` 타입을 인코딩할 수 있도록 해주는 프로토콜임 ✨
