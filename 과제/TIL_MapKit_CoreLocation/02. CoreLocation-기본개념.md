## Core Location 기본 개념

<sub> 아까 맵킷 공부할 때 어쩔 수 없이 대충 봐버렷지만 더 자세히 알아보기 위해 !!

# 01 Core Location이란?
→ 아이폰이나 아이패드의 위치를 알아내고 위치 변화를 확인할 수 있게 해주는 기능


예를 들어 MoSS에서 치이가 지금 어디에 있는지 확인하고 지도에 보여주고 싶을 때 이 기능을 사용함

> MapKit이 지도를 보여주는 역할이라면 Core Location은 현재 위치를 가져오는 역할임

# 02 Core Location은 어떤 상황에서 사용할까??
사용자의 위치를 알아야 하는 기능을 만들 때 사용
* MoSS에서 내 주변 스카나 카페를 찾을 때
* 현재 위치를 지도에 표시할 때
* 위치에 따라 날씨나 정보를 보여줄 때

<sub>ex.) 치이카와가 있는 장소를 확인해서 MoSS 지도에 표시 가능

# 03 CLLocationManager란?
→ 위치를 받아오거나 위치 업데이트를 관리하는 객체


앱은 `CLLocationManager`를 이용해 위치 권한을 확인하고 위치 정보를 요청할 수 잇음

> CLLocationManager → 위치 사용 권한 확인 → 현재 위치 요청 → 위치 업데이트 관리

위치 정보를 사용하려면 먼저 사용자에게 권한을 받아야 함

# 04 CLLocation이란?
→ 한 시점의 위치와 관련 정보를 담는 타입

`CLLocationManager`가 위치를 받아오면 `CLLocation` 형태로 위치 정보가 전달됨

<sub>ex.) 치이가 지금 있는 위치를 하나의 위치 정보로 받아올 수 있음

# 05 CLLocation에는 어떤 정보가 들어 있을까?
`CLLocation`에는 위치 좌표 외에도 다양한 정보가 들어갈 수 있음
* 위도와 경도
* 위치가 측정된 시간
* 위치의 정확도
* 고도
* 이동 속도와 방향

모든 정보가 항상 정확하거나 사용할 수 잇ㅆ는 것은 아니고 측정 환경이나 기기 상태에 따라 값이 달라질 수 있음

# 06 CLLocationManagerDelegate란?

→ 위치 요청 결과나 위치 변경을 전달받기 위한 규칙임

`CLLocationManager`가 위치를 받아오거나 오류가 생겼을 때 앱이 그 결과를 알 수 있도록 Delegate를 사용함 !!

> CLLocationManager → 위치 결과나 오류 발생 → Delegate를 통해 앱에 알림

<mark>즉, 위치 정보를 요청하는 쪽과 결과를 전달받아 처리하는 쪽을 나누는 역할을 함

# 07 위치 정보에 권한이 필요한 이유
위치 정보는 사용자의 현재 장소나 이동 경로를 알 수 있는 민감한 정보임


그래서 앱이 위치 정보를 사용하기 전에 사용자의 허가를 받아야 함 \
앱은 위치가 왜 필요한지 설명하고 사용자가 선택할 수 있게 해야 함


위치가 필요하지 않은 기능까지 무리하게 권한을 요청하지 않는 것도 중요 !

# 08 위치 권한 상태란?
iOS는 사용자가 앱의 위치 접근을 허용했는지 상태로 구분함
* `notDetrimined` : 아직 위치 권한을 선택하지 않음
* `restricted` : 기기 설정이나 보호자 관리 등으로 권한을 바꾸기 어려움
* `denied` : 사용자가 위치 접근을 허용하지 않음
* `authorizedWhenInUse` : 앱을 사용하는 동안 위치 접근을 허용함
* `authorizedAlways` : 앱을 사용하지 않을 때도 위치 접근을 허용

앱은 현재 권한 상태에 맞게 위치 기능을 사용할 수 있는지 확인해야 함

# 09 앱을 사용하는 동안 위치 접근과 항상 위치 접근

### ① 앱을 사용하는 동안 위치 접근
사용자가 앱을 사용하는 동안 위치 정보를 사용할 수 있음

<sub>ex.) MoSS를 열어 지도 화면을 보는 동안 현재 위치를 표시하는 경우에 사용 가능

### ② 항상 위치 접근
앱이 화면에 보이지 않을 때도 위치 정보를 사용할 슈 있는 권한임

위치에 따라 백그라운드에서 기능을 작동해야 하는 경우 등에 필요할 수 있음 \
사용자에게 필요한 이유를 설명하고 꼭 필요한 경우에만 요청해야 함

# 10 위치 권한을 거부 했을 때
사용자가 위치 권한을 거부했다고 해서 앱 전체를 사용하지 못하게 만들기보다 위치 기능 외의 기능은 계속 쓸 수 있게 하는 편이 좋음 !!

### 예를 들어 MoSS를 또 예시로 들자면
* 현재 위치 대신 장소를 직접 검색하게 함
* 지도는 보여주되 현재 위치는 사용할 수 없다고 안내
* 위치 기능이 필요한 이유 설명
* 사용자가 원하면 권한을 바꿀 수 있다고 설명
