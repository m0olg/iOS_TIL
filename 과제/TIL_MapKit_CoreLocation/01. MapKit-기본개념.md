## MapKit 기본 개념

# 01 MapKit이란?
→ iOS 앱에서 지도를 보여주고 지도에 정보를 표시할 수 있게 해주는 프레임워크임


예를 들어 치이 앱에 하치가 있는 장소를 지도 위에 표시하고 싶을 때 MapKit을 사용할 수 있음


Mapkit은 지도를 보여주는 역할을 함 \
사용자의 실제 위치를 알아내는 역할과는 구분됨

# 02 MapKit은 어떤 상황에서 사용할까????????
지도나 장소 정보를 앱 화면에 보여주고 싶을 때 사용함
* 가게나 약속 장소를 지도에 표시할 때
* 내가 만들 MoSS처럼 특정 위치를 핀으로 보여줄 때
* 지도에서 현재 보이는 지역을 조정할 때
* 사용자가 지도를 확대하거나 이동할 수 있게 할 때

<sup>ex.) 치이카와가 하치와레랑 만나기로 한 장소를 지도에 표시할 수 있음

# 03 지도 앱에서 MapKit이 하는 역할
MapKit은 앱에 지도를 보여주고 지도 위에 표시할 정보를 다루는 역할을 함


> 지도 화면 표시 → 지도 위치와 확대 범위 설정 → 장소 표시 → 사용자가 지도를 이동하거나 확대

지도에 표시할 좌표를 직접 정하거나 Core Location에서 위치를 받아 표시 가능함

# 04 MKMapView란?
→ UIKit에서 지도를 화면에 표시할 때 사용하는 지도 뷰

`MKMapView`를 사용하면 지도 화면을 보여주고 지도 영역을 설정하거나 Annotation을 표시할 수 있음

<sub>ex.) 또 예를 들면 치이가 있는 장소의 좌표를 받아서 지도에 표시할 수 있음

# 05 SwiftUI의 Map이란?
→ 스유에서 지도를 화면에 표시할 때 사용하는 뷰


UIkit의 `MKMapView`와 비슷한 지도 표시 기능을 SwiftUI 방식으로 사용할 수 있게 해줌


간단히 구분하자면 다음과 같음 !
* UIKit 화면에서 지도를 표시할 때 : `MKMapView`
* 스유 화면에서 지도를 표시할 때 : `Map`
둘 다 지도를 표시하고 지도 위에 위치 정보를 보여주는데 사용

# 06 CLLocationCoordinate2D란?
→ 위도와 경도로 한 지점의 위치를 표현하는 자료형임

* `latitude` : 위도
* `longitude` : 경도

<sub>ex.) 요것도 예시를 들면 치이가 있는 장소의 위치를 위도와 경도 값으로 표현하고 지도에 표시 가능 !

# 07 위도와 경도란?
~~원래설명쓰려고햇는데이건초등학교때부터계속들어서굳이써야하나싶긴한데일단개념이나와잇으니까~~

### ① 위도
적도를 기준으로 위치가 남쪽인지 북쪽인지 나타냄

### ② 경도
기준이 되는 경선을 중심으로 위치가 동쪽인지 서쪽인지 나타냄
위도와 경도를 함께 사용하면 지구 위의 한 지점을 나타낼 수 있음


# 08 MKCoordinateRegion이란?
→ 지도의 중심 위치와 화면에 보여줄 범위를 함께 나타내는 타입


**`MKCoordinateRegion`은 중심 좌표인 `center`와 지도에 보이는 범위인 `span`으로 구성 !!!!**

* `center` : 지도의 중심 좌표
* `span` : 화면에 보이는 범위

# 09 region과 span의 의미

### ① region
지도의 중심과 화면에 보이는 범위를 나타냄

<sup>또 예를 들어서 치이가 잇는 장소를 중심으로 주변 지도를 보여주도록 설정 가능함

### ② span
지도 화면에 어느 정도의 범위를 보여줄지 정함
* **작은 범위를 설정**하면 **지도가 더 확대**되어 보임
* **큰 범위를 설정**하면 **더 넓은 지역**이 보임
`span`은 특정 장소 하나를 가리키는 값이 아니라 지도 화면에 보여줄 영역의 크기를 정하는 값임
