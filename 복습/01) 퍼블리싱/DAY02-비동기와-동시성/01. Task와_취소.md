### Ⅰ. Task와 취소

<br>


# 1-1 `Task`란?

→ <mark>Swift에서 비동기 작업을 시작하고 관리하는 단위

`async` 함수는 비동기 작업의 문맥 안에서 호출해야 함  
일반 함수 안에서 비동기 작업을 시작하고 싶을 때 `Task`를 사용할 수 있음

```swift
Task {
    await loadCharacters()
}
```


<br>
<br>


# 1-2 `Task` 안에서 비동기 함수 실행하기

`Task`의 클로저 안에서는 `await`를 사용해 비동기 함수를 호출할 수 있음

```swift
func buttonTapped() {
    Task {
        await loadCharacters()
    }
}
```

버튼을 눌렀을 때 `loadCharacters()`를 비동기로 실행하는 예시임


<br>
<br>



# 1-3 오류가 발생할 수 있는 작업

비동기 함수가 오류를 던질 수 있다면 `do-catch`로 처리할 수 있음

```swift
Task {
    do {
        let characters = try await fetchCharacters()
        print(characters)
    } catch {
        print("요청 실패:", error)
    }
}
```

- `await`: 비동기 작업의 결과를 기다림
- `try`: 오류가 발생할 수 있는 함수 호출
- `catch`: 요청 중 발생한 오류 처리



<br>
<br>


# 1-4 Task 저장하기

`Task`를 프로퍼티에 저장하면 나중에 해당 작업을 취소하거나 확인할 수 있음

```swift
var loadTask: Task<Void, Never>?

func load() {
    loadTask = Task {
        await loadCharacters()
    }
}
```

`Task<Void, Never>`는 작업이 결과 값을 반환하지 않고 오류도 밖으로 던지지 않는 형태의 Task임  
오류가 필요하면 Task의 반환 타입과 오류 처리 방식이 달라질 수 있음


<br>
<br>



# 1-5 `Task.cancel()`로 작업 취소하기

저장해 둔 Task는 `cancel()`로 취소 요청을 할 수 있음

```swift
loadTask?.cancel()
```

*예를 들어*  검색어가 바뀌면 이전 검색 Task를 취소하고 새 요청을 시작할 수 있음

```swift
var searchTask: Task<Void, Never>?

func search(_ keyword: String) {
    searchTask?.cancel()

    searchTask = Task {
        await searchCharacters(keyword)
    }
}
```




<br>
<br>

# 1-6 취소는 요청임

`cancel()`은 Task에 취소 의사를 알리는 기능임  
작업이 반드시 그 순간에 바로 멈추는 것은 아님

작업을 실행하는 코드가 취소 상태를 확인하고 적절히 중단해야 함

```swift
guard !Task.isCancelled else {
    return
}
```

<br>
<br>




# 1-7 취소된 작업의 결과 처리하기

이전 요청이 취소된 뒤에도 결과 처리 코드가 실행되지 않도록 취소 상태를 확인할 수 있음

```swift
let result = try await fetchCharacters()

guard !Task.isCancelled else {
    return
}

characters = result
```

이렇게 하면 검색어가 바뀐 뒤 도착한 오래된 결과가 최신 화면을 덮어쓰는 상황을 줄일 수 있음


<br>
<br>



# 1-8 View가 사라질 때 Task 취소하기

화면이 사라지면 더 이상 필요하지 않은 작업을 취소할 수 있음

SwiftUI에서는 `.task`를 사용해 View와 연결된 비동기 작업을 실행할 수 있음

```swift
.task {
    await viewModel.loadCharacters()
}
```

View의 생명주기와 연결해 작업을 실행하면 화면이 사라질 때 작업 취소를 처리하기 편함  
<u>다만 실제로 작업이 중단되는 시점과 동작은 실행 코드가 취소를 확인하는 방식에 따라 달라질 수 있음</u>



<br>
<br>


# 1-9 정리

* `Task`는 비동기 작업을 시작하고 관리하는 단위임
* `Task` 안에서 `await`로 비동기 함수를 호출할 수 있음
* 필요한 경우 Task를 저장해 나중에 취소할 수 있음
* `cancel()`은 취소 요청이며 작업이 즉시 강제로 멈춘다는 뜻은 아님
* 작업 중 `Task.isCancelled` 등을 확인해 취소된 작업을 정리할 수 있음
* 검색어가 바뀌면 이전 요청을 취소해 오래된 결과가 화면에 반영되지 않게 할 수 있음

> ### ⇒ `Task`로 비동기 작업을 시작하고 필요 없어지면 취소 요청을 보낼 수 있음 ✨
