### Ⅲ. 네트워크 코드 테스트




# 3-1 네트워크 코드를 테스트하는 이유

> 네트워크 코드가 서버에 요청을 보내고 응답을 처리하는 과정에서 문제가 없는지 확인해야 함

실제 서버만 이용해 테스트하면 인터넷이나 서버 상태에 따라 결과가 달라질 수 있음  
그래서 <u>서버에 연결하지 않고도 앱의 데이터 처리 흐름을 확인하는 방법이 필요</u>함






# 3-2 테스트에서 확인할 내용

네트워크 기능을 테스트할 때는 다음 내용을 확인할 수 있음

- 데이터를 성공적으로 받아오는지
- 응답 데이터가 모델로 잘 변환되는지
- 응답이 비어 있을 때 알맞게 처리하는지
- 요청에 실패했을 때 오류 상태를 보여주는지






# 3-3 실제 서버 테스트의 한계

실제 서버에 요청을 보내면 테스트 결과가 서버나 네트워크 상황에 영향을 받을 수 있음

- 인터넷 연결이 필요함
- 서버가 일시적으로 중단될 수 있음
- 서버의 데이터가 변경될 수 있음
- 테스트 중 서버에 실제 데이터가 저장될 수 있음

따라서 ViewModel의 데이터 처리 동작을 확인할 때는 테스트용 객체를 사용할 수 있음
