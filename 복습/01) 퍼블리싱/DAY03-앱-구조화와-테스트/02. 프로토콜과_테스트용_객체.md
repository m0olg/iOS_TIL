### Ⅱ. 프로토콜과 테스트용 객체




# 2-1 프로토콜이란?

→ 타입이 따라야 할 기능의 규칙을 정해두는 것

프로토콜에는 필요한 메서드나 프로퍼티를 선언함  
프로토콜을 채택한 타입은 그 규칙에 맞춰 기능을 구현해야 함

```swift
protocol CharacterService {
    func fetchCharacters() async throws -> [Character]
}
```

이 프로토콜은 캐릭터 목록을 가져오는 기능이 있어야 한다는 규칙을 정함






# 2-2 프로토콜을 채택한 실제 서비스

실제 서버와 통신하는 객체가 프로토콜을 채택할 수 있음

```swift
final class CharacterAPIClient: CharacterService {
    func fetchCharacters() async throws -> [Character] {
        // 서버에 요청하고 응답을 디코딩
        []
    }
}
```

`CharacterAPIClient`는 `CharacterService`의 `fetchCharacters()`를 구현함
