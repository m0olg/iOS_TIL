### Ⅰ. 의존성 주입




# 1-1 의존성이란?

→ 한 타입이 다른 타입의 기능을 사용하는 관계

예를 들어 `CharacterViewModel`이 서버에서 캐릭터 목록을 가져오려고 `APIClient`를 사용한다면 `CharacterViewModel`은 `APIClient`에 의존함


> CharacterViewModel → APIClient를 사용함






# 1-2 의존성을 직접 만드는 방식

ViewModel 안에서 필요한 객체를 직접 만들 수 있음

```swift
final class CharacterViewModel {
    private let apiClient = CharacterAPIClient()
}
```

코드가 간단해 보이지만 `CharacterViewModel`이 `CharacterAPIClient`에 직접 연결됨  
<mark>테스트하거나 다른 구현으로 바꾸고 싶을 때 수정하기 어려워질 수 있음</mark>






# 1-3 의존성 주입이란?

→ 필요한 객체를 타입 내부에서 직접 만들지 않고 외부에서 전달받는 방식

```swift
final class CharacterViewModel {
    private let service: CharacterService

    init(service: CharacterService) {
        self.service = service
    }
}
```

`CharacterViewModel`은 서비스를 직접 만들지 않고 초기화할 때 전달받음
