### Ⅰ. 앱 생명주기와 `ScenePhase`




# 1-1 앱 생명주기란?

→ 앱이 실행되고 사용되다가 잠시 멈추거나 종료되는 상태의 흐름임

앱은 항상 화면에 떠 있는 것이 아니라 사용자의 동작에 따라 상태가 바뀜


> 앱 실행 → 화면에 보임 → 다른 앱으로 이동하거나 화면이 가려짐 → 다시 화면에 보임

앱의 상태에 따라 작업을 시작하거나 멈춰야 할 수 있음






# 1-2 앱 상태를 알아야 하는 이유

앱이 화면에 보이지 않을 때도 모든 작업을 계속하면 배터리와 자원을 불필요하게 사용할 수 있음

예를 들어 치이카와 목록을 새로고침하는 중에 사용자가 다른 화면으로 이동하면 작업을 계속할지 잠시 멈출지 고려해야 함

- 화면에 보일 때 필요한 데이터 불러오기
- 화면이 가려졌을 때 불필요한 작업 줄이기
- 앱으로 돌아왔을 때 화면 상태 확인하기






# 1-3 `ScenePhase`란?

→ SwiftUI에서 앱의 현재 실행 상태를 확인할 수 있게 해주는 값

`ScenePhase`로 앱이나 화면이 현재 활성 상태인지, 비활성 상태인지 백그라운드에 있는지 확인할 수 있음

주요 상태는 다음과 같음

- `active`: 앱이 앞에 있고 사용자의 입력을 받을 수 있음
- `inactive`: 앱이 활성 상태에서 벗어나는 중이거나 일시적으로 입력을 받지 않는 상태
- `background`: 앱이 화면 뒤로 이동한 상태
