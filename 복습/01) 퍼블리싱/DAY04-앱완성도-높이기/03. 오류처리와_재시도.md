### Ⅲ. 오류 처리와 재시도


<br>

# 3-1 오류 처리가 필요한 이유

앱을 사용하다 보면 네트워크 연결이 끊기거나 서버가 응답하지 않는 등 예상하지 못한 문제가 생길 수 있음

오류가 났을 때 화면이 멈춘 것처럼 보이거나 아무 설명도 없으면 사용자는 무슨 일이 생겼는지 알기 어려움  
그래서 오류 상황을 알아보기 쉽게 안내하고 다음 행동을 제공해야 함






# 3-2 오류 상황을 나누기

앱에서 발생하는 오류는 원인에 따라 나눠볼 수 있음

- 네트워크에 연결할 수 없음
- 서버가 성공하지 않은 응답을 보냄
- 응답 데이터를 예상한 형식으로 읽을 수 없음
- 검색 결과가 없음

검색 결과가 없는 상황은 요청 실패와 다름  
요청은 성공했지만 조건에 맞는 치이카와가 한 마리도 없을 수 있음






# 3-3 사용자가 이해하기 쉬운 안내

오류가 발생했을 때 개발자용 오류 문구를 그대로 보여주기보다 사용자가 이해하기 쉬운 설명을 보여주는 것이 좋음

```text
개발자에게 필요한 정보: 응답 디코딩 실패
사용자에게 보여줄 안내: 정보를 불러오지 못했어요 ㅜㅜ
```

오류 이유를 간단히 알려주고 가능한 경우 다시 시도하는 방법도 제공할 수 있음






# 3-4 재시도란?

→ 요청이 실패했을 때 같은 작업을 다시 시도하는 것

예를 들어 치이카와 목록을 불러오지 못했다면 사용자가 버튼을 눌러 다시 요청할 수 있음

> 요청 실패 → 오류 안내 표시 → 다시 시도 선택 → 서버에 새 요청






# 3-5 다시 시도 버튼 제공하기

실패 화면에 다시 시도 버튼을 두고 ViewModel의 요청 함수를 다시 실행할 수 있음

```swift
Button("다시 시도") {
    Task {
        await viewModel.loadCharacters()
    }
}
```

같은 요청 함수를 재사용하면 처음 데이터를 불러올 때와 다시 시도할 때 흐름을 일관되게 유지할 수 있음
