### Ⅱ. 권한과 사용자 경험


<br>

# 2-1 권한이란?

→ 앱이 사용자의 기기 정보나 기능에 접근하기 전에 받는 허가

카메라, 사진, 마이크, 위치 정보처럼 개인 정보와 연결될 수 있는 기능은 사용자의 허락이 필요함

예를 들어 치이카와 주변의 카페를 보여주는 앱이라면 현재 위치를 사용하기 전에 위치 권한을 요청해야 함



<br>
<br>

# 2-2 권한을 요청하는 이유

위치나 사진처럼 개인 정보와 관련된 기능은 사용자가 허락한 범위에서만 사용해야 함

권한을 요청할 때는 다음을 고려해야 함

- 기능에 꼭 필요한 권한만 요청하기
- 왜 필요한지 사용자가 이해하기 쉽게 설명하기
- 사용자가 거부해도 가능한 기능은 계속 사용할 수 있게 하기

<br>
<br>



# 2-3 권한 상태 확인하기

위치 권한은 사용자가 선택했는지에 따라 상태가 다름

- 아직 선택하지 않음
- 접근이 제한됨
- 사용자가 거부함
- 앱을 사용하는 동안 허용함
- 항상 허용함

앱은 권한 상태를 확인한 뒤 위치를 사용할 수 있는지 판단해야 함


<br>
<br>


# 2-4 권한을 요청하기 전에 안내하기

권한 창을 갑자기 띄우기보다 먼저 기능과 권한이 필요한 이유를 설명하는 것이 좋음

예를 들어 주변 카페를 보여주기 전에 다음과 같이 안내할 수 있음

> 내 주변 장소를 찾기 위해 위치 정보가 필요해요.

사용자가 권한 요청의 목적을 이해하면 기능을 신뢰하고 선택하기 쉬워짐

<br>
<Br>



# 2-5 권한을 허용한 경우

사용자가 위치 권한을 허용하면 앱은 허용된 범위에서 위치 기능을 사용할 수 있음

예를 들어 치이카와 주변의 장소를 지도에 표시할 수 있음

단, 권한이 있다고 해서 필요 이상으로 위치를 계속 수집해도 된다는 뜻은 아님  
앱의 기능에 필요한 범위에서 사용해야 함

<br>
<br>



# 2-6 권한을 거부한 경우

사용자가 권한을 거부하면 앱은 위치 정보 없이 가능한 기능을 계속 제공하는 것이 좋음

예를 들어 현재 위치 기반 장소 표시를 사용할 수 없더라도 장소 이름을 직접 검색하거나 지역을 선택할 수 있게 할 수 있음

- 위치를 사용할 수 없는 이유 안내하기
- 위치 없이 쓸 수 있는 대체 방법 제공하기
- 앱의 다른 기능은 계속 이용할 수 있게 하기






# 2-7 설정에서 권한 바꾸기 안내하기

사용자가 권한을 거부한 뒤 다시 위치 기능을 사용하고 싶을 수 있음  
이때 설정 앱에서 권한을 바꿀 수 있다는 안내를 보여줄 수 있음

앱이 권한을 강제로 바꿀 수는 없음  
사용자가 직접 설정을 변경해야 함






# 2-8 권한을 반복해서 요청할 때 주의하기

사용자가 이미 거부한 권한을 계속 요청하면 불편하고 압박을 느낄 수 있음

권한이 꼭 필요한 순간에 이유를 설명하고 요청해야 함  
거부한 경우에는 반복해서 권한 창을 띄우기보다 설정 방법이나 대체 기능을 안내하는 것이 좋음






# 2-9 최소한의 권한 요청

앱 기능에 필요하지 않은 권한은 요청하지 않는 것이 좋음

예를 들어 주변 장소를 보여주는 기능에는 위치 권한이 필요할 수 있지만 위치와 관계없는 화면을 이용할 때까지 위치 권한을 요구할 필요는 없음

권한을 요청하는 시점과 범위를 기능에 맞게 정해야 함






# 2-10 정리

* 권한은 앱이 위치나 카메라 같은 기기 기능을 사용하기 전에 받는 허가
* 권한을 요청하기 전에 필요한 이유를 쉽게 설명해야 함
* 사용자가 허용한 범위 안에서 필요한 만큼만 사용
* 권한이 거부되어도 가능한 기능은 계속 쓸 수 있게 하는 것이 좋음
* 권한이 꼭 필요한 순간에 요청하고 반복해서 압박하지 않아야 함
* 위치 기능을 사용할 수 없을 때는 검색이나 지역 선택 같은 대체 방법을 제공할 수 있음

> ### ⇒ 권한은 꼭 필요한 순간에 이유를 설명하고 요청하며 거부해도 쓸 수 있는 방법을 마련해야 함 ✨
