### Ⅱ. URLSession으로 데이터 요청하기




# 2-1 URLSession이란?

→ iOS 앱에서 서버와 데이터를 주고받을 때 사용하는 도구

앱은 `URLSession`으로 서버에 요청을 보내고, 서버가 돌려준 응답을 받을 수 있음

```text
앱 → 요청 → 서버
앱 ← 응답 ← 서버
```






# 2-2 URLSession의 기본 구성

`URLSession`으로 요청할 때는 보통 다음 요소를 사용함

- `URL`: 요청을 보낼 주소
- `URLRequest`: 요청 주소와 메서드, 헤더 등의 정보
- `URLSession`: 요청을 보내고 응답을 받는 역할
- `data`: 서버가 돌려준 응답 본문
- `response`: 상태 코드 등 응답에 관한 정보






# 2-3 URL 만들기

요청할 주소를 `URL`로 만들어야 함

```swift
let url = URL(string: "https://api.example.com/characters")
```

주소가 올바르지 않으면 `URL`이 만들어지지 않을 수 있으므로, 실제 앱에서는 안전하게 확인하는 편이 좋음

```swift
guard let url = URL(string: "https://api.example.com/characters") else {
    return
}
```

`api.example.com`은 예시 주소임  
실제 요청을 보낼 때는 API 문서에 안내된 주소를 사용해야 함






# 2-4 URLSession으로 GET 요청 보내기

간단한 GET 요청은 `data(from:)`를 사용해 보낼 수 있음

```swift
let (data, response) = try await URLSession.shared.data(from: url)
```

- `URLSession.shared`: 기본 설정의 세션
- `data(from:)`: URL에 요청을 보내고 응답을 받음
- `data`: 서버가 돌려준 본문 데이터
- `response`: 서버 응답 정보
- `try await`: 요청은 시간이 걸리고 오류가 발생할 수 있음을 나타냄
