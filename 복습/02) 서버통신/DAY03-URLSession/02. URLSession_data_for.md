### Ⅱ. URLSession으로 데이터 요청하기




# 2-1 URLSession이란?

→ iOS 앱에서 서버와 데이터를 주고받을 때 사용하는 도구

앱은 `URLSession`으로 서버에 요청을 보내고, 서버가 돌려준 응답을 받을 수 있음

```text
앱 → 요청 → 서버
앱 ← 응답 ← 서버
```


<br>



# 2-2 URLSession의 기본 구성

`URLSession`으로 요청할 때는 보통 다음 요소를 사용함

- `URL`: 요청을 보낼 주소
- `URLRequest`: 요청 주소와 메서드, 헤더 등의 정보
- `URLSession`: 요청을 보내고 응답을 받는 역할
- `data`: 서버가 돌려준 응답 본문
- `response`: 상태 코드 등 응답에 관한 정보






# 2-3 URL 만들기

요청할 주소를 `URL`로 만들어야 함

```swift
let url = URL(string: "https://api.example.com/characters")
```

주소가 올바르지 않으면 `URL`이 만들어지지 않을 수 있으므로, 실제 앱에서는 안전하게 확인하는 편이 좋음

```swift
guard let url = URL(string: "https://api.example.com/characters") else {
    return
}
```

`api.example.com`은 예시 주소임  
실제 요청을 보낼 때는 API 문서에 안내된 주소를 사용해야 함






# 2-4 URLSession으로 GET 요청 보내기

간단한 GET 요청은 `data(from:)`를 사용해 보낼 수 있음

```swift
let (data, response) = try await URLSession.shared.data(from: url)
```

- `URLSession.shared`: 기본 설정의 세션
- `data(from:)`: URL에 요청을 보내고 응답을 받음
- `data`: 서버가 돌려준 본문 데이터
- `response`: 서버 응답 정보
- `try await`: 요청은 시간이 걸리고 오류가 발생할 수 있음을 나타냄






# 2-5 `async`와 `await`

네트워크 요청은 응답을 받을 때까지 시간이 걸릴 수 있음  
Swift에서는 `async`와 `await`를 사용해 이런 비동기 작업을 작성할 수 있음

```swift
func fetchCharacters() async throws {
    let (data, response) = try await URLSession.shared.data(from: url)
}
```

- `async`: 함수가 비동기 작업을 수행함
- `await`: 비동기 작업의 결과를 기다림
- `throws`: 작업 중 오류가 발생할 수 있음
- `try`: 오류가 발생할 수 있는 코드를 실행함






# 2-6 `URLRequest`로 요청 설정하기

요청 메서드나 헤더처럼 요청 정보를 직접 설정하려면 `URLRequest`를 사용할 수 있음

```swift
var request = URLRequest(url: url)
request.httpMethod = "GET"
request.setValue("application/json", forHTTPHeaderField: "Accept")
```

- `URLRequest(url:)`: 요청할 URL을 지정
- `httpMethod`: HTTP 메서드를 지정
- `setValue`: 요청 헤더를 설정
- `Accept`: 받고 싶은 응답 형식을 서버에 알릴 때 사용

필요한 메서드와 헤더는 API 문서에 따라 달라질 수 있음






# 2-7 설정한 요청 보내기

`URLRequest`로 만든 요청은 `data(for:)`로 보낼 수 있음

```swift
let (data, response) = try await URLSession.shared.data(for: request)
```

요청을 보내고 나면 `data`와 `response`를 받음  
응답 본문을 읽거나 상태 코드를 확인할 때 두 값을 사용함






# 2-8 요청과 응답 확인 예시

```swift
import Foundation

func fetchCharacters() async {
    guard let url = URL(string: "https://api.example.com/characters") else {
        print("URL이 올바르지 않음")
        return
    }

    do {
        let (data, response) = try await URLSession.shared.data(from: url)

        guard let httpResponse = response as? HTTPURLResponse else {
            print("HTTP 응답이 아님")
            return
        }

        print("상태 코드:", httpResponse.statusCode)
        print("응답 데이터 크기:", data.count)
    } catch {
        print("요청 실패:", error)
    }
}
```

이 코드는 다음 순서로 동작함

1. 요청할 URL을 만듦
2. `URLSession`으로 GET 요청을 보냄
3. 응답을 받은 뒤 HTTP 응답인지 확인
4. 상태 코드를 출력
5. 요청 중 오류가 발생하면 `catch`에서 확인






# 2-9 주의할 점

- `URLSession` 요청은 비동기 작업이므로 `await`가 필요함
- 요청 중 오류가 발생할 수 있으므로 `try`와 오류 처리가 필요함
- 서버 응답을 받았더라도 요청이 성공했다는 뜻은 아님
- 성공 여부는 `HTTPURLResponse`의 상태 코드도 확인해야 함
- 실제 URL과 요청에 필요한 헤더는 API 문서를 확인해야 함






# 2-10 정리

* `URLSession`은 iOS 앱에서 서버 요청과 응답을 처리함
* `URL`은 요청 주소를 나타냄
* `URLRequest`에는 메서드와 헤더 등 요청 정보를 설정할 수 있음
* `data(from:)`나 `data(for:)`로 요청을 보낼 수 있음
* 응답으로 본문 데이터인 `data`와 응답 정보인 `response`를 받음
* 네트워크 요청은 비동기 작업이며 오류가 발생할 수 있음

> ### ⇒ URL을 준비하고 `URLSession`으로 요청을 보낸 뒤, 응답을 확인하는 흐름을 익히면 됨 ✨
