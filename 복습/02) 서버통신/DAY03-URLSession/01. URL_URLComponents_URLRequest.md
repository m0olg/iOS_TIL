### I. 요청과 응답 확인




# 3-1 요청과 응답이란?

앱이 서버에 데이터를 요청하면 서버는 처리 결과를 응답으로 돌려줌

```text
앱 → 요청 → 서버
앱 ← 응답 ← 서버
```

앱은 서버의 응답을 확인한 뒤, 데이터를 화면에 표시하거나 오류를 처리함






# 3-2 URLSession으로 요청 보내기

`URLSession`은 서버에 요청을 보내고 응답을 받는 역할

```swift
let (data, response) = try await URLSession.shared.data(for: request)
```

- `request`: 서버에 보낼 요청 정보
- `data`: 서버가 돌려준 응답 본문
- `response`: 상태 코드 등 응답에 관한 정보
- `await`: 비동기 작업의 결과를 기다림
- `try`: 요청 중 오류가 발생할 수 있음을 나타냄






# 3-3 응답 상태 확인하기

서버 응답에서 HTTP 상태 코드를 확인하려면 `response`를 `HTTPURLResponse`로 변환

```swift
guard let httpResponse = response as? HTTPURLResponse else {
    throw URLError(.badServerResponse)
}

print(httpResponse.statusCode)
```

상태 코드는 서버가 요청을 어떻게 처리했는지 나타냄 ⬇️⬇️
- `200`: 요청 성공
- `401`: 인증이 필요하거나 인증 정보에 문제가 있을 수 있음
- `404`: 요청한 자원을 찾을 수 없음
- `500`: 서버 내부에 문제가 발생함

상태 코드의 의미는 API 문서에 따라 확인해야 함






# 3-4 성공 응답인지 확인하기

응답을 받았다고 해서 요청이 항상 성공한 것은 아님  
상태 코드가 성공 범위인지 확인해야 함

```swift
guard (200...299).contains(httpResponse.statusCode) else {
    throw URLError(.badServerResponse)
}
```

> `200...299` 범위에 포함되면 일반적으로 성공 응답으로 처리함






# 3-5 응답 데이터 확인하기

응답 본문은 `Data` 타입으로 전달됨  
JSON 응답의 내용을 간단히 확인하려면 문자열로 변환할 수 있음

```swift
let responseText = String(data: data, encoding: .utf8)
print(responseText ?? "응답 내용을 읽을 수 없음")
```

실제 앱에서는 응답 JSON을 모델에 맞게 디코딩해 사용함






# 3-6 오류 확인하기

요청 과정에서 오류가 발생하면 `do-catch`로 확인할 수 있음

```swift
do {
    let (data, response) = try await URLSession.shared.data(for: request)
    print("응답 데이터 크기:", data.count)
} catch {
    print("요청 실패:", error)
}
```

요청 오류와 서버의 실패 응답은 구분해서 확인해야 함

- 요청 자체가 실패하면 `catch`에서 확인
- 서버 응답을 받았지만 처리가 실패했다면 상태 코드를 확인






# 3-7 전체 예시

```swift
do {
    let (data, response) = try await URLSession.shared.data(for: request)

    guard let httpResponse = response as? HTTPURLResponse else {
        throw URLError(.badServerResponse)
    }

    print("상태 코드:", httpResponse.statusCode)

    guard (200...299).contains(httpResponse.statusCode) else {
        throw URLError(.badServerResponse)
    }

    let responseText = String(data: data, encoding: .utf8)
    print("응답 내용:", responseText ?? "문자열 변환 실패")
} catch {
    print("요청 실패:", error)
}
```

동작 순서는 다음과 같음

1. `request`를 서버에 보냄
2. 서버의 응답 데이터와 응답 정보를 받음
3. HTTP 상태 코드를 확인함
4. 성공 응답인지 확인함
5. 응답 본문을 확인함
6. 요청 중 오류가 나면 `catch`에서 처리함






# 3-8 정리

* `URLSession`으로 요청을 보내고 응답을 받을 수 있음
* `data`에는 응답 본문이, `response`에는 응답 정보가 들어 있음
* `HTTPURLResponse`의 `statusCode`로 서버 응답을 확인함
* 응답을 받았더라도 성공 상태 코드인지 확인해야 함
* 요청 오류와 서버의 실패 응답은 구분해서 확인해야 함
* 실제 요청 형식과 응답 내용은 API 문서를 기준으로 확인해야 함
