### I. URL, URLComponents, URLRequest




# 1-1 URL이란?

→ 서버의 주소와 요청할 자원의 위치를 나타내는 주소

```text
https://api.example.com/characters/1?language=ko
```

URL은 다음처럼 나눠 볼 수 있음

- `https`: 통신 방식
- `api.example.com`: 호스트, 서버 주소
- `/characters/1`: 경로
- `language=ko`: 쿼리 파라미터

실제 요청에 사용할 URL은 API 문서에 안내된 주소를 확인해야 함






# 1-2 URL을 코드로 만들기

Swift에서는 문자열 주소를 `URL`로 만들 수 있음

```swift
let url = URL(string: "https://api.example.com/characters")
```

주소 형식이 올바르지 않으면 `nil`이 될 수 있으므로, 실제 코드에서는 안전하게 확인하는 편이 좋음

```swift
guard let url = URL(string: "https://api.example.com/characters") else {
    return
}
```






# 1-3 URLComponents란?

→ URL을 구성 요소별로 나누어 만들거나 수정할 때 사용하는 타입

쿼리 파라미터를 문자열로 직접 이어 붙이면 특수문자나 띄어쓰기 때문에 주소가 잘못 만들어질 수 있음  
`URLComponents`를 사용하면 URL의 각 부분과 쿼리 항목을 따로 설정할 수 있음

```swift
var components = URLComponents()
components.scheme = "https"
components.host = "api.example.com"
components.path = "/characters"
```

- `scheme`: 통신 방식
- `host`: 서버 주소
- `path`: 요청할 경로






# 1-4 쿼리 파라미터 추가하기

쿼리 파라미터는 `URLQueryItem`으로 설정할 수 있음

```swift
components.queryItems = [
    URLQueryItem(name: "page", value: "2"),
    URLQueryItem(name: "limit", value: "20")
]
```

이렇게 설정하면 다음과 같은 형태의 URL을 만들 수 있음

```text
https://api.example.com/characters?page=2&limit=20
```

- `name`: 파라미터 이름
- `value`: 파라미터 값

파라미터의 의미와 이름은 API 문서를 확인해야 함






# 1-5 URLComponents에서 URL 만들기

설정한 `URLComponents`에서 `URL`을 가져올 수 있음

```swift
guard let url = components.url else {
    return
}
```

전체 예시는 다음과 같음

```swift
var components = URLComponents()
components.scheme = "https"
components.host = "api.example.com"
components.path = "/characters"
components.queryItems = [
    URLQueryItem(name: "page", value: "2"),
    URLQueryItem(name: "limit", value: "20")
]

guard let url = components.url else {
    return
}
```






# 1-6 URLRequest란?

→ 서버에 보낼 요청 정보를 담는 타입

`URLRequest`에는 URL뿐 아니라 HTTP 메서드, 헤더 같은 요청 정보도 설정할 수 있음

```swift
var request = URLRequest(url: url)
request.httpMethod = "GET"
```

- `URLRequest(url:)`: 요청할 URL 지정
- `httpMethod`: HTTP 메서드 설정

여기서 `GET`은 요청 메서드의 예시임  
요청 목적에 따라 사용할 메서드는 API 문서를 확인해야 함






# 1-7 요청 헤더 설정하기

헤더에는 요청에 필요한 부가 정보를 담을 수 있음

```swift
request.setValue(
    "application/json",
    forHTTPHeaderField: "Accept"
)
```

`Accept`는 앱이 받고 싶은 응답 형식을 서버에 알려줄 때 사용함

인증 토큰처럼 다른 헤더가 필요한 경우도 있지만, 필요한 헤더 이름과 값은 API 문서에 따라 설정해야 함






# 1-8 URL과 URLRequest 함께 만들기

`URLComponents`로 URL을 만들고, 그 URL을 이용해 `URLRequest`를 설정할 수 있음

```swift
var components = URLComponents()
components.scheme = "https"
components.host = "api.example.com"
components.path = "/characters"

guard let url = components.url else {
    return
}

var request = URLRequest(url: url)
request.httpMethod = "GET"
request.setValue(
    "application/json",
    forHTTPHeaderField: "Accept"
)
```

이 코드에서는 다음을 준비함

1. URL의 통신 방식, 서버 주소, 경로 설정
2. `URLComponents`에서 URL 생성
3. 생성한 URL로 `URLRequest` 생성
4. 요청 메서드와 헤더 설정






# 1-9 URL을 만들 때 주의할 점

- 실제 서버 주소와 경로는 API 문서에서 확인해야 함
- 쿼리 파라미터의 이름과 의미도 API 문서에 따라야 함
- URL 문자열을 직접 이어 붙이기보다 `URLComponents`를 사용하는 편이 안전함
- URL이나 `URLComponents`에서 URL을 만들 때 값이 없을 수 있으므로 확인이 필요함
- 인증 정보 같은 민감한 값은 주소에 함부로 넣지 말고, API에서 안내한 방식으로 전달해야 함






# 1-10 정리

* `URL`은 요청할 주소를 나타냄
* `URLComponents`는 URL을 부분별로 구성하거나 쿼리 파라미터를 추가할 때 사용함
* `URLQueryItem`으로 쿼리 파라미터의 이름과 값을 설정할 수 있음
* `URLRequest`는 URL, 메서드, 헤더 등 요청 정보를 담음
* 실제 주소, 파라미터, 메서드, 헤더는 API 문서를 기준으로 확인해야 함

> ### ⇒ URL로 주소를 만들고, `URLRequest`에 요청 정보를 담아 서버에 보낼 준비를 함 ✨
