### Ⅰ. Query Parameter와 URL 구성




# 1-1 Query Parameter란?

→ 요청할 데이터의 조건이나 옵션을 URL에 추가하는 값

예를 들어 캐릭터 목록에서 두 번째 페이지를 요청하고 싶다면 `page`라는 Query Parameter를 사용할 수 있음

```text
https://api.example.com/characters?page=2
```

- `?`: Query Parameter가 시작되는 위치
- `page=2`: 파라미터 이름과 값
- `&`: 파라미터가 여러 개일 때 연결






# 1-2 Query Parameter를 사용하는 경우

Query Parameter는 요청할 데이터의 조건이나 범위를 지정할 때 자주 사용함

- 특정 페이지 조회
- 한 번에 가져올 데이터 개수 지정
- 검색어 전달
- 정렬 순서 지정
- 필터 조건 전달

```text
/characters?page=2&limit=20
```

- `page=2`: 두 번째 페이지 요청
- `limit=20`: 한 번에 가져올 데이터 개수

파라미터의 이름과 의미는 API마다 다르므로 API 문서를 확인해야 함






# 1-3 URLComponents로 Query Parameter 구성하기

URL에 파라미터를 문자열로 직접 이어 붙일 수도 있지만, 특수문자나 공백이 들어가면 URL이 의도한 대로 만들어지지 않을 수 있음

`URLComponents`와 `URLQueryItem`을 사용하면 URL과 파라미터를 나누어 설정할 수 있음

```swift
var components = URLComponents()
components.scheme = "https"
components.host = "api.example.com"
components.path = "/characters"
components.queryItems = [
    URLQueryItem(name: "page", value: "2"),
    URLQueryItem(name: "limit", value: "20")
]
```

- `scheme`: 통신 방식
- `host`: 서버 주소
- `path`: 요청할 경로
- `queryItems`: Query Parameter 목록






# 1-4 URLComponents에서 URL 만들기

설정한 `URLComponents`에서 실제 요청에 사용할 `URL`을 가져옴

```swift
guard let url = components.url else {
    print("URL을 만들 수 없음")
    return
}
```

전체 예시는 다음과 같음

```swift
var components = URLComponents()
components.scheme = "https"
components.host = "api.example.com"
components.path = "/characters"
components.queryItems = [
    URLQueryItem(name: "page", value: "2"),
    URLQueryItem(name: "limit", value: "20")
]

guard let url = components.url else {
    print("URL을 만들 수 없음")
    return
}

print(url)
```

만들어진 URL은 다음과 같은 형태가 됨

```text
https://api.example.com/characters?page=2&limit=20
```






# 1-5 검색어를 Query Parameter로 전달하기

검색어처럼 공백이나 한글이 들어갈 수 있는 값도 `URLQueryItem`으로 설정할 수 있음

```swift
components.queryItems = [
    URLQueryItem(name: "query", value: "하치와레")
]
```

`URLComponents`가 URL에 맞는 형식으로 값을 구성해 줌  
다만 파라미터 이름과 값의 형식은 API 문서에 정의된 대로 사용해야 함






# 1-6 Query Parameter가 없을 수도 있을 때

조건에 따라 파라미터를 추가하거나 생략할 수 있음

```swift
var queryItems = [
    URLQueryItem(name: "page", value: "1")
]

if let searchText = searchText {
    queryItems.append(
        URLQueryItem(name: "query", value: searchText)
    )
}

components.queryItems = queryItems
```

검색어가 있을 때만 `query` 파라미터를 추가하는 예시임






# 1-7 Query Parameter와 Path의 차이

### Path

요청할 자원이나 대상의 위치를 나타냄

```text
/characters/1
```

특정 캐릭터를 가리키는 경로로 사용할 수 있음

### Query Parameter

요청 조건이나 옵션을 전달함

```text
/characters?page=2
```

캐릭터 목록의 페이지를 지정하는 조건으로 사용할 수 있음

각 값이 실제로 어떤 의미인지는 API 문서를 확인해야 함






# 1-8 URL 요청 예시

```swift
import Foundation

var components = URLComponents()
components.scheme = "https"
components.host = "api.example.com"
components.path = "/characters"
components.queryItems = [
    URLQueryItem(name: "page", value: "2"),
    URLQueryItem(name: "limit", value: "20")
]

guard let url = components.url else {
    print("URL을 만들 수 없음")
    return
}

var request = URLRequest(url: url)
request.httpMethod = "GET"
```

이 코드에서는 다음 내용을 준비함

1. `URLComponents`로 URL의 구성 요소를 설정
2. `URLQueryItem`으로 Query Parameter를 추가
3. `components.url`에서 URL을 생성
4. 생성한 URL로 `URLRequest`를 만듦
5. 요청 메서드를 설정






# 1-9 Query Parameter 구성 시 주의할 점

- 파라미터 이름과 값의 의미는 API 문서를 확인해야 함
- 파라미터가 여러 개면 `URLQueryItem`을 여러 개 추가할 수 있음
- 문자열을 직접 이어 붙이기보다 `URLComponents`를 사용하면 URL을 구성하기 편함
- 값이 없을 때 파라미터를 보낼지 생략할지는 API 문서를 확인해야 함
- 인증 토큰처럼 민감한 정보는 Query Parameter에 넣지 말고 API가 안내한 방식으로 전달해야 함






# 1-10 정리

* Query Parameter는 요청 조건이나 옵션을 URL에 전달함
* Query Parameter는 URL에서 `?` 뒤에 나타남
* 여러 파라미터는 `&`로 연결됨
* `URLComponents`와 `URLQueryItem`으로 URL과 파라미터를 구성할 수 있음
* Path는 요청 대상을 나타내고 Query Parameter는 조건이나 옵션을 전달하는 데 자주 사용함
* 실제 파라미터 이름과 의미는 API 문서를 기준으로 확인해야 함

> ### ⇒ `URLComponents`로 URL을 구성하고 `URLQueryItem`으로 요청 조건을 추가 ✨
