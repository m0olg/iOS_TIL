### Ⅱ. Header와 인증 토큰

<br>



# 2-1 Header란?

→ HTTP 요청이나 응답에 필요한 부가 정보를 담는 부분

Header에는 본문 데이터 자체가 아니라, 데이터 형식이나 인증 정보처럼 요청·응답을 처리할 때 필요한 정보가 들어감

```text
요청 URL
HTTP 메서드
Header
본문
```

> 어떤 Header가 필요한지는 API 문서를 확인해야 함


<br>
<br>



# 2-2 자주 사용하는 Header

### `Accept`

클라이언트가 받고 싶은 응답 형식을 서버에 알려줌

```swift
request.setValue(
    "application/json",
    forHTTPHeaderField: "Accept"
)
```

### `Content-Type`

요청 본문에 담긴 데이터의 형식을 서버에 알려줌

```swift
request.setValue(
    "application/json",
    forHTTPHeaderField: "Content-Type"
)
```

`Accept`는 **받고 싶은 형식**, `Content-Type`은 **보내는 본문의 형식**을 나타냄


<br>
<br>



# 2-3 URLRequest에 Header 설정하기

`URLRequest`의 `setValue(_:forHTTPHeaderField:)`를 사용해 Header를 추가할 수 있음

```swift
var request = URLRequest(url: url)

request.setValue(
    "application/json",
    forHTTPHeaderField: "Accept"
)
```

Header 이름과 값은 서버 API에서 요구하는 형식에 맞춰야 함


<br>
<br>



# 2-4 인증 토큰이란?

→ 서버가 사용자의 로그인이나 권한을 확인할 때 사용하는 값

로그인 후 서버가 인증 토큰을 발급하면, 앱은 이후 요청에 토큰을 포함해 사용자를 인증할 수 있음

토큰을 보내는 방식은 API마다 다르지만, 흔히 `Authorization` Header를 사용함



<br>
<br>


# 2-5 Authorization Header 설정하기

서버가 `Bearer` 방식을 안내했다면 보통 다음처럼 설정함

```swift
request.setValue(
    "Bearer \(token)",
    forHTTPHeaderField: "Authorization"
)
```

- `Authorization`: 인증 정보를 전달하는 Header 이름
- `Bearer`: 인증 방식의 접두어
- `token`: 서버에서 발급받은 인증 토큰

`Bearer`를 포함할지, Header 이름이나 형식이 무엇인지는 API 문서에서 확인해야 함

<br>
<br>




# 2-6 Header를 여러 개 설정하기

요청에 필요한 Header를 각각 설정할 수 있음

```swift
var request = URLRequest(url: url)

request.setValue(
    "application/json",
    forHTTPHeaderField: "Accept"
)

request.setValue(
    "application/json",
    forHTTPHeaderField: "Content-Type"
)

request.setValue(
    "Bearer \(token)",
    forHTTPHeaderField: "Authorization"
)
```

모든 요청에 Header가 필요한 것은 아님  
API 문서에서 요청에 필요한 Header를 확인하고 설정해야 함


<br>
<br>



# 2-7 토큰을 다룰 때 주의할 점

- 토큰은 로그인 정보와 연결될 수 있는 민감한 값임
- 토큰을 코드에 직접 적거나 공개 저장소에 올리지 않음
- 토큰을 URL의 Query Parameter로 보내지 말고, API가 안내한 방식으로 전달함
- 토큰이 만료되었거나 올바르지 않으면 서버가 인증 오류를 응답할 수 있음
- 토큰 저장과 관리 방법은 앱의 보안 방식과 서버 정책에 맞춰야 함


<br>
<br>



# 2-8 정리

* Header는 요청이나 응답에 필요한 부가 정보를 담음
* `Accept`는 받고 싶은 응답 형식, `Content-Type`은 보내는 본문의 형식을 나타냄
* `URLRequest`의 `setValue`로 Header를 설정할 수 있음
* 인증 토큰은 보통 `Authorization` Header로 전달함
* 토큰의 전달 형식과 필요한 Header는 API 문서를 확인해야 함
* 토큰은 민감한 정보이므로 코드나 URL에 노출하지 않도록 주의함

<br>

> ### ⇒ Header에 요청에 필요한 정보를 설정하고, 인증 토큰은 API에서 안내한 방식으로 전달함 ✨
