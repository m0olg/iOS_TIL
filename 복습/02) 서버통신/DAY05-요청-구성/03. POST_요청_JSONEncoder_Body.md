### Ⅲ. POST 요청, JSONEncoder, Body

<br>


# 3-1 POST 요청이란?

→ 서버에 데이터를 보내거나 새로운 데이터를 만들 때 사용하는 HTTP 요청 방식

예를 들어 치이카와의 새 게시글을 서버에 등록할 때, 게시글 정보를 POST 요청으로 보낼 수 있음

```text
POST /posts
```

POST 요청에는 서버에 전달할 데이터를 **요청 본문(Body)**에 담을 수 있음  
요청 메서드와 주소, 전달할 데이터는 API 문서를 확인해야 함


<br>
<br>



# 3-2 요청 Body란?

→ 서버에 전달할 데이터를 담는 부분

예를 들어 게시글 제목과 내용을 서버에 보내려면 다음 정보를 Body에 담을 수 있음

```json
{
  "title": "치이카와의 하루",
  "content": "하치와레와 함께 놀았어요."
}
```

모든 요청에 Body가 필요한 건 아님  
어떤 데이터를 어떤 형식으로 보내야 하는지는 API 문서에 정의되어 있음

<br>
<br>




# 3-3 서버에 보낼 Swift 모델 만들기

앱에서 보낼 데이터를 Swift 타입으로 정의할 수 있음

```swift
struct PostRequest: Encodable {
    let title: String
    let content: String
}
```

`Encodable`은 Swift 값을 JSON 같은 외부 데이터 형식으로 변환할 수 있게 해주는 프로토콜임

서버에 보낼 JSON 키와 자료형에 맞춰 모델을 만들어야 함



<br>
<br>


# 3-4 JSONEncoder란?

→ Swift 값을 JSON 데이터로 변환할 때 사용하는 타입

```swift
let post = PostRequest(
    title: "치이카와의 하루",
    content: "하치와레와 함께 놀았어요."
)

let encoder = JSONEncoder()
let body = try encoder.encode(post)
```

- `JSONEncoder()`: Swift 값을 JSON으로 바꿔주는 인코더
- `encode(post)`: `post`를 JSON 데이터로 변환
- `body`: 변환된 JSON `Data`

인코딩 과정에서 오류가 발생할 수 있으므로 `try`를 사용함


<br>
<br>



# 3-5 URLRequest에 POST 설정하기

`URLRequest`에 요청 주소와 HTTP 메서드를 설정함

```swift
var request = URLRequest(url: url)
request.httpMethod = "POST"
```

- `URLRequest(url:)`: 요청할 주소를 설정
- `httpMethod`: HTTP 요청 방식을 설정

서버가 요구하는 메서드와 주소는 API 문서를 확인해야 함


<br>
<br>



# 3-6 Content-Type 설정하기

요청 Body에 JSON을 담아 보낼 때는 Body의 형식을 Header에 알려줘야 함

```swift
request.setValue(
    "application/json",
    forHTTPHeaderField: "Content-Type"
)
```

`Content-Type`은 요청 Body의 데이터 형식을 서버에 알려주는 Header임

<br>
<br>




# 3-7 인코딩한 데이터를 Body에 넣기

`URLRequest`의 `httpBody`에 인코딩한 JSON 데이터를 넣음

```swift
request.httpBody = body
```

전체 흐름은 다음과 같음

```text
Swift 모델
→ JSONEncoder로 JSON Data 변환
→ URLRequest의 Body에 설정
→ 서버로 요청 전송
```

<br>
<br>




# 3-8 POST 요청 보내기

요청 정보가 준비되면 `URLSession`으로 서버에 전송할 수 있음

```swift
let (data, response) = try await URLSession.shared.data(for: request)
```

- `data`: 서버가 돌려준 응답 본문
- `response`: 서버 응답에 관한 정보

요청 자체가 실패할 수 있으므로 `try await`를 사용함


<br>
<br>



# 3-9 POST 요청 전체 예시

```swift
import Foundation

struct PostRequest: Encodable {
    let title: String
    let content: String
}

func createPost() async throws {
    guard let url = URL(string: "https://api.example.com/posts") else {
        return
    }

    let post = PostRequest(
        title: "치이카와의 하루",
        content: "하치와레와 함께 놀았어요."
    )

    let body = try JSONEncoder().encode(post)

    var request = URLRequest(url: url)
    request.httpMethod = "POST"
    request.setValue(
        "application/json",
        forHTTPHeaderField: "Content-Type"
    )
    request.httpBody = body

    let (data, response) = try await URLSession.shared.data(for: request)

    print("응답 데이터:", data)
    print("응답 정보:", response)
}
```

이 코드는 다음 순서로 동작함

1. 서버 주소를 `URL`로 만듦
2. 보낼 내용을 `PostRequest` 인스턴스로 만듦
3. `JSONEncoder`로 모델을 JSON `Data`로 변환
4. `URLRequest`에 `POST` 메서드를 설정
5. `Content-Type` Header를 설정
6. JSON 데이터를 요청 Body에 넣음
7. `URLSession`으로 요청을 보냄



<br>
<br>


# 3-10 응답 상태 코드 확인하기

서버 응답을 받으면 상태 코드도 확인해야 함

```swift
guard let httpResponse = response as? HTTPURLResponse else {
    throw URLError(.badServerResponse)
}

print("상태 코드:", httpResponse.statusCode)
```

서버가 응답을 돌려줬다고 해서 요청이 성공한 것은 아님  
성공 여부는 상태 코드와 API 문서를 함께 확인해야 함


<br>
<br>



# 3-11 POST 요청에서 주의할 점

- POST 요청의 URL, Body 구조, 필수 Header는 API 문서를 확인해야 함
- JSON 키 이름과 자료형이 서버가 기대하는 형식과 맞아야 함
- JSON Body를 보낼 때 `Content-Type` 설정이 필요한지 확인해야 함
- 인증이 필요한 API라면 안내된 방식으로 인증 Header도 설정해야 함
- 요청 성공 여부를 확인할 때 응답 상태 코드도 확인해야 함


<br>
<br>



# 3-12 정리

* POST는 서버에 데이터를 보내거나 새 데이터를 만들 때 주로 사용함
* 보낼 데이터는 요청 Body에 담을 수 있음
* `Encodable` 모델은 Swift 데이터를 인코딩할 수 있게 함
* `JSONEncoder`는 Swift 값을 JSON `Data`로 변환함
* 인코딩한 `Data`는 `URLRequest`의 `httpBody`에 넣음
* JSON Body의 형식을 알리려면 `Content-Type` Header를 설정함
* `URLSession`으로 요청을 보낸 뒤 응답과 상태 코드를 확인함

<br>

> ### ⇒ Swift 모델을 `JSONEncoder`로 변환하고, `URLRequest`의 Body에 담아 서버에 전송함 ✨
