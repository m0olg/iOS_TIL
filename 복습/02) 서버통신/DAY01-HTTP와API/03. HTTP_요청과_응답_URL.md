# 3-1 HTTP란?
→ 클라이언트랑 서버가 요청과 응답을 주고 받을 때 사용하는 통신 규칙

> 앱이 서버에 <mark>데이터를 요청할 땐 HTTP 요청</mark>을 보내고
> 서버는 처리 결과를 <mark>HTTP 응답으로 돌려줌</mark>

HTTPS는 HTTP 통신에 보안 계층을 더한 방식임 \
실제 사용자 정보나 인증 정보가 오갈 수 있으므로 HTTPS를 사용하는 경우가 일반적
