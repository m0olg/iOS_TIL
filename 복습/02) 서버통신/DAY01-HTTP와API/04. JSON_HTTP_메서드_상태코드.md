### Ⅳ. JSON, HTTP 메서드와 상태 코드

# 4-1 JSON이란?
→ 서버와 앱이 데이터를 주고받을 때 자주 사용하는 데이터 형식

JSON은 사람이 읽기 쉽고 여러 프로그래밍 언어에서 사용할 수 있음

> 서버가 JSON으로 응답하면 iOS 앱은 응답 데이터를 Swift 타입으로 변환해서 사용함  
> 이 변환은 나중에 배울 `Codable`이랑 연결됨 !!

<BR>
<BR>



# 4-2 JSON의 기본 구조
### 1) 객체 (Object)
중괄호 `{}`로 감싸고 `키: 값` 형태로 데이터를 표현

```json
{
  "id": 1,
  "name": "Mina",
  "isDone": false
}
```

- `"id"`는 키, `1`은 값
- `"name"`은 키, `"Mina"`는 값
- JSON의 키는 문자열로 작성함

### 2) 배열 (Array)
대괄호 `[]`로 감싸고 여러 값을 순서대로 담음

```json
[
  {
    "id": 1,
    "name": "Mina"
  },
  {
    "id": 2,
    "name": "Jin"
  }
]
```

이건 객체 2개가 들어 있는 배열임  
서버에서 목록을 가져올 때 이런 구조를 자주 볼 수 있음

<BR>
<BR>



# 4-3 JSON에서 사용하는 값
JSON에는 이런 종류의 값이 있음

| 종류 | 예시 |
|---|---|
| 문자열 | `"name": "Mina"` |
| 숫자 | `"id": 1` |
| 불리언 | `"isDone": false` |
| 객체 | `"user": { "id": 1 }` |
| 배열 | `"items": [1, 2, 3]` |
| 값 없음 | `"memo": null` |

문자열 `"1"`이랑 숫자 `1`은 서로 다른 값임  
Swift 타입을 정할 때는 실제 JSON 값의 타입을 확인해야 함

# 4-4 HTTP 메서드란?
→ 클라이언트가 서버에 어떤 작업을 요청하는지 나타냄

### 1) `GET`
데이터를 조회할 때 사용함

> ex - 사용자 목록이나 게시글 상세 내용 가져오기

### 2) `POST`
새로운 데이터를 만들거나 서버에 데이터를 전달할 때 사용함

> ex - 새 게시글 작성, 로그인 정보 전달

### 3) `PUT`
기존 데이터를 전체적으로 교체할 때 사용함

### 4) `PATCH`
기존 데이터의 일부를 수정할 때 사용함

> ex - 사용자 정보 중 닉네임만 변경

### 5) `DELETE`
서버에 저장된 데이터를 삭제할 때 사용함

> 메서드의 구체적인 사용 방식은 API에 따라 다를 수 있으니 API 문서를 확인해야 함


<BR>
<BR>


# 4-5 HTTP 상태 코드란?
→ 서버가 요청을 처리한 결과를 숫자로 알려줌

### 1) 성공 응답
- `200` : 요청이 성공적으로 처리됨
- `201` : 요청으로 새로운 데이터가 생성됨
- `204` : 요청은 성공했지만 응답 본문은 없음

### 2) 클라이언트 요청 관련 오류
- `400` : 요청 형식이나 값이 잘못됨
- `401` : 인증이 필요하거나 인증 정보가 유효하지 않음
- `403` : 요청한 작업을 할 권한이 없음
- `404` : 요청한 경로나 데이터를 찾을 수 없음

### 3) 서버 오류
- `500` : 서버 내부에서 오류가 발생함
- `503` : 서버가 일시적으로 요청을 처리할 수 없음

상태 코드만으로 오류의 정확한 원인을 알 수 없는 경우도 있어서 API 문서랑 응답 본문도 같이 확인해야 함


<BR>
<BR>


# 4-6 상태 코드와 응답 본문
상태 코드는 요청 처리 결과를 간단하게 알려주고, 응답 본문에는 데이터나 자세한 오류 설명이 들어갈 수 있음

ex - 서버가 `404` 상태 코드와 함께 이런 JSON을 보낼 수 있음

```json
{
  "message": "User not found"
}
```

여기서 상태 코드는 대상을 찾지 못했다는 결과를 알려주고  
응답 본문은 구체적인 오류 메시지를 전달함

반대로 `204`처럼 요청은 성공했지만 응답 본문이 없는 경우도 있음


<BR>
<BR>


# 4-7 예시 요청 살펴보기
### 사용자 목록 조회
- 메서드: `GET`
- 목적: 사용자 목록을 가져오기
- 응답: 사용자 정보가 담긴 JSON 배열일 수 있음
- 성공 상태 코드: API에 따라 `200` 등으로 응답할 수 있음

### 게시글 작성
- 메서드: `POST`
- 목적: 게시글 정보를 서버에 전달해서 새 게시글 만들기
- 요청 본문: 제목과 내용이 담긴 JSON일 수 있음
- 성공 상태 코드: API에 따라 `201` 등으로 응답할 수 있음

위 내용은 일반적인 예시임  
실제 메서드와 응답 형식은 API 문서에 적힌 내용을 따라야 함

<BR>
<BR>



# 4-8 정리
* JSON은 서버와 앱이 데이터를 주고받을 때 자주 사용하는 형식
* JSON 객체는 `{}`, 배열은 `[]`로 표현
* HTTP 메서드는 요청의 목적을 나타냄
* 상태 코드는 서버가 요청을 처리한 결과를 알려줌
* 오류가 발생하면 상태 코드뿐 아니라 응답 본문과 API 문서도 확인해야 함
