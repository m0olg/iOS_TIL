### Ⅲ. `Task`, `MainActor`, UI 갱신

<br>

# 3-1 `Task`란?

→ 비동기 작업을 시작할 때 사용하는 타입

`async` 함수는 비동기 작업의 문맥 안에서 호출해야 함  
`Task`를 사용하면 일반 코드에서 비동기 작업을 시작할 수 있음

```swift
Task {
    await fetchData()
}
```

`Task` 안에서는 `await`를 사용해 비동기 함수를 호출할 수 있음


<br>
<br>


# 3-2 `Task`로 네트워크 요청하기

버튼을 눌렀을 때 서버에서 데이터를 가져오는 상황을 생각해보자

```swift
func loadData() {
    Task {
        let data = try await fetchData()
        print(data)
    }
}
```

`loadData()`는 일반 함수지만, 내부에 `Task`를 만들어 비동기 작업을 시작함


<br>
<br>



# 3-3 `Task`에서 오류 처리하기

네트워크 요청은 실패할 수 있으므로 `do-catch`로 오류를 처리함

```swift
func loadData() {
    Task {
        do {
            let data = try await fetchData()
            print(data)
        } catch {
            print("요청 실패:", error)
        }
    }
}
```

`Task` 안에서도 `try await`로 요청하고, `catch`에서 오류를 처리할 수 있음


<br>
<br>



# 3-4 UI 갱신은 메인 스레드에서

화면에 보이는 UI는 메인 스레드에서 갱신해야 함

네트워크 요청처럼 시간이 걸리는 작업은 비동기로 처리하고, 결과를 화면에 표시할 때는 UI를 안전한 위치에서 갱신해야 함

```text
네트워크 요청
→ 응답 데이터 받기
→ 화면에 결과 표시
```


<br>
<br>



# 3-5 `MainActor`란?

→ UI와 관련된 작업을 메인 실행 흐름에서 처리하도록 하는 기능

`@MainActor`를 사용하면 해당 타입이나 함수의 작업을 메인 액터에서 실행하도록 지정할 수 있음

```swift
@MainActor
func updateUI() {
    // 화면에 표시할 값 갱신
}
```

SwiftUI의 상태 값이나 UIKit 화면을 업데이트할 때 `MainActor`를 활용할 수 있음


<br>
<br>



# 3-6 `MainActor.run`으로 UI 갱신하기

비동기 작업의 결과를 받은 뒤, UI 변경 부분을 `MainActor.run` 안에서 실행할 수 있음

```swift
Task {
    do {
        let data = try await fetchData()

        await MainActor.run {
            label.text = "데이터를 불러왔어요"
        }
    } catch {
        await MainActor.run {
            label.text = "데이터를 불러오지 못했어요"
        }
    }
}
```

- 네트워크 요청은 `Task`에서 비동기로 진행
- 화면에 표시하는 코드는 `MainActor.run` 안에서 실행



<br>
<br>


# 3-7 `@MainActor`를 타입에 적용하기

UI를 관리하는 타입 전체에 `@MainActor`를 붙일 수도 있음

```swift
@MainActor
final class CharacterViewModel {
    var characterName = ""

    func updateName(_ name: String) {
        characterName = name
    }
}
```

이 타입의 프로퍼티와 메서드는 메인 액터에서 사용되도록 관리됨  
화면 상태를 관리하는 뷰 모델에 적용할 수 있음



<br>
<br>


# 3-8 네트워크 요청 후 UI 갱신하기

```swift
@MainActor
final class CharacterViewModel {
    var characterName = ""
    var errorMessage = ""

    func loadCharacter() {
        Task {
            do {
                let character = try await fetchCharacter()
                characterName = character.name
            } catch {
                errorMessage = "캐릭터 정보를 불러오지 못했어요."
            }
        }
    }
}
```

이 예시에서는 다음처럼 동작함

1. `loadCharacter()`에서 `Task`를 시작
2. `fetchCharacter()`로 서버 데이터를 비동기 요청
3. 성공하면 `characterName`을 갱신
4. 실패하면 `errorMessage`를 갱신
5. 뷰 모델이 `@MainActor`에 있으므로 UI와 연결된 값이 메인 액터에서 관리됨


<br>
<br>



# 3-9 주의할 점

- 네트워크 요청이 오래 걸려도 UI가 멈추지 않도록 비동기로 처리함
- 화면에 연결된 상태 값은 메인 액터에서 갱신해야 함
- `Task` 안에서 오류가 발생할 수 있으면 `do-catch`로 처리함
- `MainActor`는 네트워크 요청을 더 빠르게 만드는 기능이 아니라, UI 작업을 올바른 실행 흐름에서 처리하도록 하는 기능임
- 실제 프로젝트 구조에 따라 `@MainActor`를 타입이나 필요한 코드에 적용함


<br>
<br>



# 3-10 정리

* `Task`는 일반 코드에서 비동기 작업을 시작할 때 사용함
* `Task` 안에서 `await`로 비동기 함수를 호출할 수 있음
* 네트워크 요청 결과를 화면에 반영할 때는 UI 갱신 위치를 신경 써야 함
* `MainActor`는 UI 관련 작업을 메인 실행 흐름에서 처리하도록 함
* 오류가 발생할 수 있는 요청은 `do-catch`로 처리함
