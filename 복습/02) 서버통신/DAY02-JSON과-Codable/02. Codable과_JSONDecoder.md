### Ⅱ. Codable과 JSONDecoder

<br>


# 2-1 Codable이란?

→ JSON 데이터를 Swift에서 다루기 쉽게 변환할 수 있게 해주는 프로토콜

서버에서 JSON을 받으면 앱에서 사용할 Swift 타입으로 바꿔야 함  
반대로 앱의 데이터를 JSON으로 바꿔 서버에 보낼 때도 있음

```swift
struct Character: Codable {
    let id: Int
    let name: String
}
```

`Codable`을 채택한 `Character` 타입은 JSON 데이터를 Swift 값으로 바꾸거나, Swift 값을 JSON 데이터로 바꾸는 데 사용할 수 있음


<br>
<br>


# 2-2 Encodable과 Decodable

`Codable`은 두 프로토콜을 합쳐 부르는 이름임

- `Decodable`: JSON 데이터를 Swift 타입으로 변환
- `Encodable`: Swift 타입을 JSON 데이터로 변환
- `Codable`: 두 기능을 모두 포함

서버 <mark>응답 JSON을 앱에서 읽을 때는 주로 디코딩</mark>을 사용함

> JSON 데이터 → Swift 모델

<mark>서버로 데이터를 보낼 때는 주로 인코딩</mark>을 사용함 !!

> Swift 모델 → JSON 데이터


<br>
<br>


# 2-3 JSONDecoder로 디코딩하기

서버에서 받은 JSON `Data`를 Swift 모델로 바꿀 때 `JSONDecoder`를 사용함

```swift
struct Character: Decodable {
    let id: Int
    let name: String
}

let decoder = JSONDecoder()
let character = try decoder.decode(Character.self, from: data)
```

각 부분의 의미는 다음과 같음

- `JSONDecoder()`: JSON 데이터를 해석할 객체
- `Character.self`: 변환할 Swift 타입
- `data`: 서버에서 받은 JSON 데이터
- `try`: 디코딩 중 오류가 발생할 수 있음을 표시

디코딩에 실패할 수 있으므로 보통 `do-catch`로 오류를 처리함

```swift
do {
    let character = try JSONDecoder().decode(Character.self, from: data)
    print(character.name)
} catch {
    print("JSON 디코딩 실패:", error)
}
```

# 2-4 JSON 구조와 Swift 모델 맞추기

서버 JSON의 키와 자료형에 맞춰 Swift 모델을 만들어야 함

### JSON ⬇️⬇️

```json
{
  "id": 1,
  "name": "치이카와"
}
```

### Swift 모델 ⬇️⬇️

```swift
struct Character: Decodable {
    let id: Int
    let name: String
}
```

JSON에서 `"id"`는 숫자라서 `Int`, `"name"`은 문자열이라서 `String`으로 선언함

JSON의 자료형과 Swift 프로퍼티의 자료형이 맞지 않으면 디코딩에 실패할 수 있음


<br>
<br>


# 2-5 중첩된 JSON 디코딩하기

JSON 객체 안에 다른 객체가 있으면 Swift 모델도 중첩 구조에 맞춰 만들 수 있음

### JSON ⬇️⬇️

```json
{
  "id": 1,
  "profile": {
    "favoriteFood": "푸딩",
    "friend": "하치와레"
  }
}
```

### Swift 모델 ⬇️⬇️

```swift
struct Character: Decodable {
    let id: Int
    let profile: Profile
}

struct Profile: Decodable {
    let favoriteFood: String
    let friend: String
}
```

`Character` 안의 `profile` 타입을 `Profile`로 선언


<br>
<br>


# 2-6 배열 JSON 디코딩하기

JSON 응답이 여러 객체로 이루어진 배열일 수도 있음

### JSON ⬇️⬇️

```json
[
  {
    "id": 1,
    "name": "치이카와"
  },
  {
    "id": 2,
    "name": "하치와레"
  },
  {
    "id": 3,
    "name": "우사기"
  }
]
```

Swift에서는 다음처럼 배열로 디코딩할 수 있음

```swift
let characters = try JSONDecoder().decode([Character].self, from: data)
```

`[Character].self`는 `Character` 객체가 여러 개 들어 있는 배열 타입을 뜻함

# 2-7 JSON 키 이름과 프로퍼티 이름이 다를 때

서버 JSON의 키 이름과 Swift 프로퍼티 이름이 다르면 `CodingKeys`를 사용할 수 있음
### JSON ⬇️⬇️

```json
{
  "character_id": 1,
  "character_name": "치이카와"
}
```

### Swift 모델 ⬇️⬇️

```swift
struct Character: Decodable {
    let characterId: Int
    let characterName: String

    enum CodingKeys: String, CodingKey {
        case characterId = "character_id"
        case characterName = "character_name"
    }
}
```

`CodingKeys`에서 JSON 키와 Swift 프로퍼티를 연결


<br>
<br>


# 2-8 옵셔널과 누락될 수 있는 값

응답에서 값이 없을 수도 있다면 옵셔널로 선언할 수 있음

```swift
struct Character: Decodable {
    let id: Int
    let name: String
    let nickname: String?
}
```

`nickname` 값이 응답에서 빠지거나 `null`일 수 있을 때 `String?`로 표현할 수 있음

반대로 필수 프로퍼티가 JSON에 없거나 자료형이 맞지 않으면 디코딩 오류가 발생할 수 있음 ㅠㅠ


<br>
<br>


# 2-9 정리

* `Decodable`은 JSON 데이터를 Swift 타입으로 변환할 때 사용
* `Encodable`은 Swift 타입을 JSON 데이터로 변환할 때 사용
* `Codable`은 두 기능을 모두 포함
* `JSONDecoder`의 `decode`로 JSON `Data`를 모델 타입으로 변환
* JSON 구조와 Swift 모델의 구조·자료형이 맞아야 함
* 키 이름이 다르면 `CodingKeys`로 연결
* 빠질 수 있는 값은 옵셔널로 표현할 수 있음
