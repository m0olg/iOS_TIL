### Ⅰ. 배열 응답 모델링과 디코딩


<br>


# 1-1 배열 응답이란?

서버는 하나의 데이터뿐 아니라 여러 데이터를 배열 형태로 응답할 수 있음

예를 들어 캐릭터 목록을 요청하면 여러 캐릭터 정보가 JSON 배열로 올 수 있음

```json
[
  {
    "id": 1,
    "name": "치이카와"
  },
  {
    "id": 2,
    "name": "하치와레"
  },
  {
    "id": 3,
    "name": "우사기"
  }
]
```

각 객체가 배열의 요소 하나에 해당함



<br>
<br>


# 1-2 배열 요소에 맞는 모델 만들기

JSON 객체 한 개의 구조에 맞춰 Swift 모델을 만듦

```swift
struct Character: Decodable {
    let id: Int
    let name: String
}
```

- `"id"`는 숫자이므로 `Int`
- `"name"`은 문자열이므로 `String`

JSON의 키와 자료형은 실제 응답 및 API 문서에 맞춰야 함



<br>
<br>


# 1-3 배열 응답 디코딩하기

JSON이 객체 하나가 아니라 객체들의 배열이면 `[Character]` 타입으로 디코딩함

```swift
let characters = try JSONDecoder().decode(
    [Character].self,
    from: data
)
```

- `Character.self`: 디코딩할 객체 하나의 타입
- `[Character].self`: `Character`가 여러 개 들어 있는 배열 타입
- `data`: 서버에서 받은 JSON 데이터



<br>
<br>


# 1-4 배열 응답의 구조 확인하기

서버 응답이 배열 자체인지 객체 안에 배열이 들어 있는지 먼저 확인해야 함

### 1) 배열 자체가 응답인 경우

```json
[
  {
    "id": 1,
    "name": "치이카와"
  }
]
```

이 경우 `[Character].self`로 디코딩함

### 2) 객체 안에 배열이 있는 경우

```json
{
  "characters": [
    {
      "id": 1,
      "name": "치이카와"
    }
  ]
}
```

이 경우 응답 전체를 표현하는 모델이 필요함

```swift
struct CharacterListResponse: Decodable {
    let characters: [Character]
}
```

응답 전체를 디코딩할 때는 다음처럼 사용함

```swift
let response = try JSONDecoder().decode(
    CharacterListResponse.self,
    from: data
)
```


<br>
<br>



# 1-5 배열 디코딩 전체 예시

```swift
import Foundation

struct Character: Decodable {
    let id: Int
    let name: String
}

func decodeCharacters(from data: Data) throws -> [Character] {
    try JSONDecoder().decode([Character].self, from: data)
}
```

서버 응답이 JSON 배열이라면 디코딩 결과로 `Character` 값이 여러 개 들어 있는 배열을 얻음

<br>
<br>




# 1-6 디코딩한 배열 사용하기

디코딩 결과는 일반 Swift 배열처럼 사용할 수 있음

```swift
let characters = try JSONDecoder().decode(
    [Character].self,
    from: data
)

for character in characters {
    print(character.name)
}
```

`for`문을 사용해 배열의 각 캐릭터에 접근할 수 있음


<br>
<br>



# 1-7 응답이 빈 배열일 때

서버가 데이터가 없다는 뜻으로 빈 배열을 응답할 수 있음

```json
[]
```

빈 배열은 디코딩에 성공할 수 있음  
디코딩 결과가 비어 있는지 확인해 화면에서 빈 결과 상태를 처리할 수 있음

```swift
if characters.isEmpty {
    print("표시할 캐릭터가 없음")
}
```

> <mark>빈 배열과 요청 실패는 서로 다른 상황임


<br>
<br>



# 1-8 배열 디코딩 오류 확인하기

배열 응답이 예상한 모델과 다르면 디코딩 오류가 발생할 수 있음

확인할 내용은 다음과 같음

- 응답이 배열인지 객체인지
- 배열 요소의 키가 모델과 맞는지
- JSON 값의 자료형이 모델과 맞는지
- 필수 값이 빠져 있지 않은지
- 응답이 오류 메시지 등 다른 구조로 오지 않았는지

```swift
do {
    let characters = try JSONDecoder().decode(
        [Character].self,
        from: data
    )
    print(characters)
} catch {
    print("배열 디코딩 실패:", error)
}
```


<br>
<br>



# 1-9 정리

* 서버는 여러 데이터를 JSON 배열로 응답할 수 있음
* 배열 요소 한 개의 JSON 구조에 맞춰 모델을 만듦
* 배열 응답은 `[모델타입].self`로 디코딩함
* 응답이 객체 안에 배열을 담고 있다면 전체 응답 모델이 필요함
* 빈 배열은 디코딩 성공일 수 있으므로 요청 실패와 구분해야 함
* 실제 응답 구조와 키·자료형은 API 문서를 기준으로 확인해야 함

<br>

> ### ⇒ 응답이 배열인지 객체인지 먼저 확인하고 그 구조에 맞는 모델로 디코딩함 ✨
