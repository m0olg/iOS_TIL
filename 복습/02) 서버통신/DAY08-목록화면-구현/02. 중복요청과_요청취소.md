### Ⅱ. API 목록을 화면에 표시하기

<br>


# 2-1 디코딩한 목록을 화면에 표시하는 흐름

서버에서 받은 JSON 배열을 Swift 모델 배열로 디코딩한 뒤 화면에 표시함

> 서버 응답 → JSON 디코딩 → ViewModel에 목록 저장 → View가 목록을 화면에 표시


<br>
<br>



# 2-2 ViewModel에 목록 저장하기

ViewModel이 화면에 표시할 데이터를 배열로 관리함 !!

```swift
@MainActor
final class CharacterViewModel {
    private(set) var characters: [Character] = []
}
```

`characters`에는 서버에서 받아 디코딩한 캐릭터 목록이 저장

<br>
<br>




# 2-3 APIClient로 목록 가져오기

APIClient가 서버 요청과 디코딩을 담당한다고 가정함

```swift
final class CharacterAPIClient {
    func fetchCharacters() async throws -> [Character] {
        guard let url = URL(string: "https://api.example.com/characters") else {
            throw URLError(.badURL)
        }

        let (data, _) = try await URLSession.shared.data(from: url)
        return try JSONDecoder().decode([Character].self, from: data)
    }
}
```

실제 URL과 응답 구조는 API 문서를 확인해야 함


<br>
<br>



# 2-4 ViewModel에서 목록 불러오기

ViewModel은 APIClient에 목록을 요청하고 결과를 저장함

```swift
@MainActor
final class CharacterViewModel {
    private let apiClient = CharacterAPIClient()
    private(set) var characters: [Character] = []
```

요청이 성공하면 `characters`가 갱신되고 실패하면 오류를 처리함


<br>
<br>



# 2-5 View에서 목록 불러오기

View는 화면이 나타날 때 ViewModel에 데이터 요청을 시작하도록 할 수 있음

```swift
Task {
    await viewModel.loadCharacters()
}
```

SwiftUI에서는 화면이 나타날 때 실행되는 기능과 연결할 수 있음  
화면 프레임워크에 따라 호출 방식은 달라질 수 있음


<br>
<br>



# 2-6 목록의 각 요소 표시하기

화면에서는 배열을 순회하며 각 항목을 표시함

### SwiftUI 예시 ⬇️⬇️

```swift
List(viewModel.characters, id: \.id) { character in
    Text(character.name)
}
```

- `viewModel.characters`: 화면에 표시할 배열
- `id: \.id`: 각 항목을 구분할 식별자
- `character.name`: 각 행에 표시할 이름

각 항목을 구분할 수 있도록 모델에 고유한 식별자가 있는지 확인해야 함


<br>
<br>



# 2-7 ViewModel 변경을 View에 알리기

화면이 ViewModel의 데이터 변경을 알아차리고 다시 그릴 수 있도록 관찰 가능한 상태로 관리해야 함

SwiftUI에서는 사용하는 방식에 따라 `@Observable`이나 `ObservableObject` 등을 활용할 수 있음

구체적인 문법은 프로젝트의 Swift 버전과 구조에 따라 달라질 수 있지만 핵심 흐름은 같음

> ViewModel의 목록 변경 → View가 변경을 감지 → 화면에 새 목록 표시

<br>
<br>




# 2-8 정리

* 서버 응답을 모델 배열로 디코딩한 뒤 ViewModel에 저장함
* ViewModel은 목록을 요청하고 화면에 필요한 데이터를 관리함
* View는 ViewModel의 배열을 사용해 목록을 표시함
* 각 행을 구분하려면 모델의 고유 식별자가 필요함
* 데이터 변경을 View가 감지할 수 있도록 상태를 관찰 가능하게 구성해야 함
* 실제 요청 주소와 응답 구조는 API 문서를 기준으로 확인해야 함

<br>

> ### ⇒ 배열을 디코딩해 ViewModel에 저장하고 View에서 각 요소를 목록으로 표시 ✨
