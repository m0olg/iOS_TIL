# 2-1 예제 코드

치이카와 목록을 서버에 요청해서 화면에 저장하는 코드임

```swift
struct Character: Decodable {
    let id: Int
    let name: String
}

@MainActor
final class CharacterViewModel {
    private(set) var characters: [Character] = []
    private(set) var message = ""

    func loadCharacters() async {
        message = "불러오는 중 로딩중 아이엔쥐..."

        do {
            guard let url = URL(string: "https://api.example.com/characters") else {
                message = "주소가 잘못됐어요"
                return
            }

            let (data, response) = try await URLSession.shared.data(from: url)

            guard let httpResponse = response as? HTTPURLResponse,
                  (200...299).contains(httpResponse.statusCode) else {
                message = "서버 응답에 문제가 있어요"
                return
            }

            characters = try JSONDecoder().decode([Character].self, from: data)
            message = characters.isEmpty
                ? "치이카와 목록이 텅ㅌ텅 비어 있어요"
                : "목록을 불러왔어요"
        } catch {
            message = "목록을 불러오지 못했어요 ㅠㅠ"
        }
    }
}
```

# 2-2 코드 흐름 살펴보기

### ① 서버 응답 모델 만들기

```swift
struct Character: Decodable {
    let id: Int
    let name: String
}
```

서버에서 받는 캐릭터 한 명의 정보를 담는 타입임  
JSON의 `id`는 숫자라서 `Int`, `name`은 문자열이라서 `String`으로 적음

### ② 화면에 보여줄 값 준비하기

```swift
private(set) var characters: [Character] = []
private(set) var message = ""
```

`characters`에는 서버에서 받은 캐릭터 목록을 담고, `message`에는 화면에 보여줄 안내 문구를 담음

### ③ 요청이 시작되면 안내 문구 바꾸기

```swift
message = "불러오는 중 로딩중 아이엔주ㅟ..."
```

서버에 요청하기 전에 화면에 로딩 중이라는 상태를 표시함

### ④ 서버에 요청하고 응답 받기

```swift
let (data, response) = try await URLSession.shared.data(from: url)
```

`URLSession`으로 요청을 보내고 서버에서 응답 데이터와 응답 정보를 받음  
요청은 시간이 걸릴 수 있어서 `await`를 쓰고 실패할 수 있어서 `try`를 씀

### ⑤ 상태 코드 확인하기

```swift
guard let httpResponse = response as? HTTPURLResponse,
      (200...299).contains(httpResponse.statusCode) else {
    message = "서버 응답에 문제가 있어요."
    return
}
```

서버 응답이 HTTP 응답인지 확인하고, 상태 코드가 성공 범위인지 검사함  
성공 범위가 아니면 안내 문구를 바꾸고 함수를 끝냄

### ⑥ JSON을 캐릭터 배열로 바꾸기

```swift
characters = try JSONDecoder().decode([Character].self, from: data)
```

서버에서 받은 JSON `data`를 `[Character]`, 즉 캐릭터 여러 명의 배열로 바꿈

### ⑦ 결과에 맞게 안내하기

```swift
message = characters.isEmpty
    ? "치이카와 목록이 텅텅 비어 있어요"
    : "목록을 불러왔어요"
```

목록이 비었으면 빈 결과 문구를 보여주고, 캐릭터가 있으면 불러오기 완료 문구를 보여줌

### ⑧ 요청 중 오류 처리하기

```swift
} catch {
    message = "목록을 불러오지 못했어요 ㅠㅠ"
}
```

URL 요청이나 JSON 디코딩 중 오류가 나면 `catch`에서 실패 안내를 보여줌

# 2-3 전체 흐름 정리

> 로딩 문구 표시 → 서버에 요청 → 응답 상태 코드 확인 → JSON을 Character 배열로 변환 → 결과가 있으면 완료 문구 표시 → 오류가 나면 실패 문구 표시
