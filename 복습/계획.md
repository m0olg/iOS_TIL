## 2주 복습 계획

# 🎨 퍼블리싱 — 4일

**1일 차:** 진짜 완전 기초 복습 (텍스트, 스택, 화면 구성 등)

**2일 차:** modifier 적용 방법과 순서를 익히고, 폰트·색상·여백·도형을 활용해 화면 꾸미기

**3일 차:** `@State`로 상태에 따라 화면이 바뀌는 흐름을 익히고 `Button`과 `TextField`로 사용자 입력 복습

**4일 차:** `ScrollView`와 리스트를 만들고, `NavigationStack`으로 화면 이동 연결 해보기

# ⚡ 서버 통신 — 10일

**1일 차:** 클라이언트·서버·API의 관계를 이해하고, HTTP 요청과 응답, URL, JSON, 메서드와 상태 코드 살펴보기

**2일 차:** JSON 구조를 읽고, `Codable`과 `JSONDecoder`로 JSON을 Swift 타입으로 변환하기. `CodingKeys`와 옵셔널도 익히기

**3일 차:** `URL`, `URLComponents`, `URLRequest`, `URLSession`의 역할을 공부하고 간단한 `GET` 요청 보내기

**4일 차:** 동기와 비동기 처리의 차이를 이해하고, `async/await`, `throws`, `do-catch`, `Task`로 요청과 오류 처리하기

**5일 차:** Query Parameter와 Header를 설정하고, `POST` 요청의 JSON 본문을 만들어 서버에 보내기

**6일 차:** 네트워크 요청 코드를 분리하고, APIClient·오류 타입·프로토콜을 활용해 구조 정리하기

**7일 차:** ViewModel에서 데이터와 화면 상태를 관리하는 흐름 익히기

**8일 차:** 배열 형태의 API 응답을 디코딩해 목록 화면에 연결하고, 새로고침과 화면 상태 갱신 구현하기

**9일 차:** 검색어를 요청에 전달하고, 중복 요청·요청 취소·네트워크 디버깅 방법 살펴보기

**10일 차:** 서버 통신의 전체 흐름을 복습하고 할 수 있으면 실습까지
